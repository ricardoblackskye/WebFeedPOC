# Plan: Test Issue for DF issue 759

Story: #262
Issue: [#262](https://github.com/ricardoblackskye/webfeedpoc/issues/262)

## Goal

A single, home-page-scoped UI addition: append an italic footer line reading 'Built by the Dark Factory - by the Developer Agent' to the end of the home page component (src/pages/HomePage.jsx), the page component bound to the '/' route. The italics come from the semantic `<em>` element, so no stylesheet is created or modified. The site-wide shell (src/App.jsx) and its .app-footer, which render on every route, are deliberately left untouched so no other page changes. The change is developed test-first with a new unit test file for the home page component, and the regression gate checks the prerendered '/' HTML plus the existing test, lint and browser suites.

## Approach

The home page is the index route of the app shell: src/entry-server.jsx declares '<Route index element={`<HomePage />`} />' for '/' and src/main.jsx declares the same, so everything the story calls 'the home page' is composed by src/pages/HomePage.jsx (it imports ProductList, ProductModal, CategoryFilter, SortControls and Pagination and reads { products, loading, error, categories, productCounts, addToCart } from useOutletContext()). The edit is therefore one JSX addition as the last child of the fragment HomePage returns, after the conditional ProductModal block: a `<footer> wrapping a <p> that wraps <em>Built by the Dark Factory - by the Developer Agent</em>. <em> is chosen because it delivers the requested italics with browser default styling — no class, no CSS file, and no change to src/App.jsx, whose .app-footer renders on every route and would otherwise leak the line onto product, category, about and architecture pages and break 'no other changes'. The work is test-first: a new vitest file, src/pages/HomePage.test.jsx, mounts HomePage the way the app does (HelmetProvider + MemoryRouter, useOutletContext stubbed with an empty product list) and asserts (a) the exact copy renders — getByText also fails loudly if the string is duplicated, (b) the matched node is an <em> inside a <footer>`, which is the reliable proof of italics because jsdom does not apply stylesheets, and (c) the pre-existing home page content ('All Items' heading, 'No products available') still renders. Verification then moves up a level: the prerender build renders '/' through src/entry-server.jsx and the HTML-only grep proves the string appears in dist/index.html and in no other prerendered page. Review focus, in likelihood order: the exact copy including casing and the single hyphen; the string appearing exactly once on the page; italic rendering surviving the app's global stylesheet once the page is really displayed (checked in the built markup, not only in jsdom); the line not leaking onto other routes that share the App shell; and the SSR/prerender path rendering the new markup without error.

## Tasks

### 1. Render the Dark Factory footer line on the home page

**Objective:** Add the italic copy 'Built by the Dark Factory - by the Developer Agent' as a footer line at the end of the home page component, driven by a failing-first unit test that pins the exact copy, its italic element and the untouched existing content.

**Files:** `src/pages/HomePage.jsx`, `src/pages/HomePage.test.jsx`

**Steps:**

1. Write the failing test file `src/pages/HomePage.test.jsx` (new file — the repository has no test for the home page component today):

```jsx
import { describe, it, expect, vi } from 'vitest'
import { render, screen } from '@testing-library/react'
import { MemoryRouter } from 'react-router-dom'
import { HelmetProvider } from 'react-helmet-async'
import HomePage from './HomePage'

const FOOTER_TEXT = 'Built by the Dark Factory - by the Developer Agent'

vi.mock('react-router-dom', async () => {
  const actual = await vi.importActual('react-router-dom')
  return {
    ...actual,
    useOutletContext: () => ({
      products: [],
      loading: false,
      error: null,
      categories: [],
      productCounts: { All: 0 },
      addToCart: vi.fn(),
    }),
  }
})

const renderHomePage = () =>
  render(
    <HelmetProvider>
      <MemoryRouter>
        <HomePage />
      </MemoryRouter>
    </HelmetProvider>
  )

describe('HomePage footer line', () => {
  it('renders the Dark Factory footer line with the exact copy', () => {
    renderHomePage()
    expect(screen.getByText(FOOTER_TEXT)).toBeDefined()
  })

  it('renders the footer line in italics (em element)', () => {
    renderHomePage()
    const line = screen.getByText(FOOTER_TEXT)
    expect(line.tagName).toBe('EM')
    expect(line.closest('footer')).not.toBeNull()
  })

  it('keeps the existing home page content unchanged', () => {
    renderHomePage()
    expect(screen.getByRole('heading', { name: /All Items/ })).toBeDefined()
    expect(screen.getByText('No products available')).toBeDefined()
  })
})
```
2. Run `npx vitest run src/pages/HomePage.test.jsx`. Expected: FAIL — 'Unable to find an element with the text: Built by the Dark Factory - by the Developer Agent' for the first two cases; the third case (existing content) passes already and must stay passing.
3. In `src/pages/HomePage.jsx`, add the footer as the last child of the fragment returned by HomePage(), immediately after the `{selectedProduct && <ProductModal ... />}` block: `<footer><p><em>Built by the Dark Factory - by the Developer Agent</em></p></footer>`. Use `<em>` (browser-default italics) and add no class, no stylesheet, no import and no other markup: the story allows no other changes, so `src/App.jsx` (whose `.app-footer` renders on every route) and all `.css` files stay untouched.
4. Run `npx vitest run src/pages/HomePage.test.jsx`. Expected: PASS — 3 tests.
5. Run `npm test -- --run` (full vitest suite). Expected: PASS — no existing component test regressed.
6. Commit: `git add src/pages/HomePage.jsx src/pages/HomePage.test.jsx && git commit -m 'feat(home): add italic Dark Factory footer line to the home page'`

**Verification:** `npx vitest run src/pages/HomePage.test.jsx` reports 3 passing tests; `npm test -- --run` reports the whole vitest suite green.

### 2. Regression gate: the copy exists only on the home page

**Objective:** Prove the addition is confined to the home page — the prerendered '/' HTML contains the line exactly once and no other prerendered page does, lint is clean, the existing browser suite still passes, and only the intended files changed.

**Files:** `src/pages/HomePage.jsx`

**Steps:**

1. Run `npm run lint`. Expected: exit 0 with no new warnings (the added JSX introduces no imports and no variables).
2. Run `npm run build:prerender`. Expected: 'Prerendering complete — N/N pages rendered'; '/' is rendered through src/entry-server.jsx, which reaches src/pages/HomePage.jsx.
3. Run `grep -rl --include='*.html' 'Built by the Dark Factory' dist/`. Expected: only `dist/index.html` — the home page. The `--include='*.html'` filter excludes the client JS bundle, which contains the string as bundled source.
4. Run `grep -c 'Built by the Dark Factory' dist/index.html`. Expected: 1 (rendered once, only by the home page route).
5. Run `npx playwright test --config playwright.config.cjs --project=chromium-desktop`. Expected: the existing browser suite passes against the Vite dev server the config starts.
6. Run `git status --short` and `git diff --stat`. Expected: `src/pages/HomePage.jsx` is the only modified file and `src/pages/HomePage.test.jsx` is the only new file — no stylesheet, no `src/App.jsx`, no route or config file touched.

**Verification:** `grep -rl --include='*.html' 'Built by the Dark Factory' dist/` prints only `dist/index.html`; `npm run lint` exits 0; `npx playwright test --config playwright.config.cjs --project=chromium-desktop` passes; `git diff --stat` lists only `src/pages/HomePage.jsx`.
