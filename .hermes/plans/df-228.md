# Plan: Test issue for dark factory #672

Story: #228
Issue: [#228](https://github.com/ricardoblackskye/webfeedpoc/issues/228)

## Goal

Add one italic credit line — 'Built by the Dark Factory - by the Developer Agent' — directly beneath the main product list on the home page. The change is confined to the existing ProductList component, its stylesheet and its colocated test suite: no new component, route, prop, hook, data flow or dependency is introduced.

## Approach

The home page's main list of products is rendered by ProductList. The route table in src/entry-server.jsx maps '/' to src/pages/HomePage.jsx, and HomePage imports ProductList from '../components/ProductList' and renders it as `<ProductList products={paginatedProducts} onAddToCart={addToCart} />, immediately followed by <Pagination />. The story asks for one footer line below that list, so the credit is appended to the bottom of ProductList's render output: a single <p className="product-list-footer"> whose only child is an <em>` containing the exact string 'Built by the Dark Factory - by the Developer Agent'.

File choice and its consequence: src/pages/HomePage.jsx is the page the evidence names, but it is not present in this repository's existing-file list, so it cannot be a target. ProductList (src/components/ProductList.jsx) is the existing component that IS the main list of products on the home page and is the only place the line can be appended to sit below the products without touching the page. Accepted consequence: because ProductList is a shared component, the line also appears wherever ProductList is mounted (e.g. the category route), and it does not appear while HomePage is in its loading or no-products state, because HomePage does not mount ProductList then (condition: !loading && paginatedProducts.length > 0). This is consistent with 'below the main list of products' and avoids introducing a conditional prop, which would be a change beyond the story.

Italics: `<em>` gives the line semantic emphasis and italic rendering in every browser; a font-style: italic rule on .product-list-footer in ProductList.css makes the italic explicit and survives any global em { font-style: normal } reset. The copy is plain ASCII — a single hyphen-minus with surrounding spaces, no curly quotes — and the test asserts it exactly.

TDD and scope: four assertions (exact text, italic emphasis, position after the last product card, exactly one instance) plus one regression assertion are added to the colocated Vitest + Testing Library suite src/components/ProductList.test.jsx and observed to fail before any JSX exists. Only then is the JSX constant and the CSS rule added. The task closes with the full suite, lint and typecheck, and git diff --stat proving exactly three files changed — that is the mechanical evidence for 'No other changes'.

Review Focus (inputs/conditions the story implies but does not state, most likely first):
1. Empty or fully-filtered product list — HomePage renders 'No products found' / 'No products available' instead of ProductList, so no credit line is shown; that matches 'below the main list of products' and must not be 'fixed' by adding a new branch.
2. Loading state — HomePage renders 'Loading products...' and no ProductList, so no credit line; same reasoning.
3. Pagination — the credit must render exactly once, after the current page's cards, and must not duplicate when the page changes.
4. Filtering/search/sorting — the credit stays a single trailing element of the rendered list, not per card and not re-ordered by sort.
5. Markup validity / copy fidelity — the paragraph must be a sibling of the list container, never a child of a ul/ol, and must use the ASCII hyphen version of the string so the assertion and the rendered page agree.

const CREDIT_TEXT = 'Built by the Dark Factory - by the Developer Agent'

it('renders the Dark Factory credit line with the exact required text', () => {
  render(`<ProductList products={products} onAddToCart={vi.fn()} />`)
  expect(screen.getByText('Built by the Dark Factory - by the Developer Agent')).toBeDefined()
})

it('renders the credit line as italic emphasis (`<em>`)', () => {
  render(`<ProductList products={products} onAddToCart={vi.fn()} />`)
  const credit = screen.getByText(CREDIT_TEXT)
  expect(credit.tagName).toBe('EM')
})

it('renders the credit line after the last product card', () => {
  const { container } = render(`<ProductList products={products} onAddToCart={vi.fn()} />`)
  const credit = screen.getByText(CREDIT_TEXT)
  const cards = container.querySelectorAll('.product-card')
  expect(cards.length).toBeGreaterThan(0)
  const lastCard = cards[cards.length - 1]
  expect(lastCard.compareDocumentPosition(credit) & Node.DOCUMENT_POSITION_FOLLOWING).toBeTruthy()
})

it('renders exactly one credit line for a multi-product list', () => {
  render(`<ProductList products={products} onAddToCart={vi.fn()} />`)
  expect(screen.getAllByText(CREDIT_TEXT)).toHaveLength(1)
})

it('still renders every product in the list (regression)', () => {
  render(`<ProductList products={products} onAddToCart={vi.fn()} />`)
  products.forEach(product => expect(screen.getByText(product.name)).toBeDefined())
})
