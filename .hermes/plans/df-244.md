# Plan: Dark Factory Test issue for issue #703

Story: #244
Issue: [#244](https://github.com/ricardoblackskye/webfeedpoc/issues/244)

## Goal

Add a single presentational line to the home page: a footer credit reading 'Built by the Dark Factory - by the Developer Agent' wrapped in a semantic `<em>` so it renders in italics. The credit is rendered by the home page route component src/pages/HomePage.jsx (the index route of '/'), not by the App shell, so it never leaks onto /about, /architecture, product or category routes. No props, state, data fetching, routing, CSS, or other components change, and a colocated home page test pins the exact copy, the italic emphasis, and the unchanged existing home page content.

## Approach

The home page is src/pages/HomePage.jsx: the route table in src/entry-server.jsx declares '/ -> `<App/>`' with `<Route index element={<HomePage />} />`, src/main.jsx mirrors that tree client-side, and scripts/prerender.mjs prerenders the '/' route into dist/index.html. HomePage owns all home-page-only content (CategoryFilter, the 'All Items' heading with product count, SortControls, ProductList + Pagination, the loading/error/empty states, and the ProductModal branch) and returns it from one fragment. The new footer line therefore goes there, as the last child of that fragment, after the `{selectedProduct && <ProductModal ... />}` block and before the closing `</>`: a `<footer>` containing `<p><em>Built by the Dark Factory - by the Developer Agent</em></p>`. The italics come from `<em>` (semantic emphasis plus the browser default font-style), so no CSS file, class name, or inline style is introduced - the story asks for italics and nothing else. Deliberately NOT src/App.jsx: the App shell renders on every route and already owns the `.app-footer` with the copyright line, so putting the credit there would show it on /about, /architecture, category and product pages and violate both 'to the home page' and 'No other changes'. The markup is static text with no hook, effect, or browser API, so it survives SSR/prerender and hydration unchanged and adds nothing to the initial render cost. Because the credit renders outside every conditional branch, it appears in all home page states (loading, error, empty catalogue, populated grid). Testing uses a colocated suite (the pattern every component in this repo already follows, e.g. src/components/ProductList.test.jsx next to src/components/ProductList.jsx): HomePage is rendered inside MemoryRouter -> Routes -> a pathless layout route whose Outlet supplies the context HomePage consumes via useOutletContext (products/loading/error/categories/productCounts/addToCart), wrapped in HelmetProvider because HomePage mounts Helmet when products exist. The suite asserts the exact copy, an EM tag, exactly one occurrence, and that the pre-existing 'All Items' heading still renders; a final check greps the prerendered dist/index.html to prove the credit reaches the static home page.

## Tasks

### 1. Add the italic Dark Factory credit to the home page

**Objective:** src/pages/HomePage.jsx renders the footer line 'Built by the Dark Factory - by the Developer Agent' inside an `<em>` element, proven by a failing-first colocated page test.

**Files:** `src/pages/HomePage.jsx`, `src/pages/HomePage.test.jsx`

**Steps:**

1. Create src/pages/HomePage.test.jsx (colocated with the page, matching the repo convention of a *.test.jsx next to every component) with a render harness: HelmetProvider > MemoryRouter initialEntries=['/'] > Routes > a pathless layout route rendering `<Outlet context={outletContext} />` > <Route index element={`<HomePage />`} />, where outletContext = { products: [], loading: false, error: null, categories: [], productCounts: { All: 0 }, addToCart: vi.fn() }. HomePage reads that object with useOutletContext, uses useSearchParams (needs the router) and renders Helmet (needs the provider).
2. Add the first failing test in `describe('HomePage Dark Factory credit', ...)`: 'renders the Dark Factory build credit with the exact story copy' - render the harness, then expect(screen.getByText('Built by the Dark Factory - by the Developer Agent')).toBeDefined().
3. Add the second failing test: 'renders the credit in italics via an `<em>` element' - render the harness, take const credit = screen.getByText('Built by the Dark Factory - by the Developer Agent'), and expect(credit.tagName).toBe('EM').
4. Run: npx vitest run src/pages/HomePage.test.jsx. Expected: FAIL with "Unable to find an element with the text: Built by the Dark Factory - by the Developer Agent" - the page has no such line yet.
5. Implement in src/pages/HomePage.jsx: add, as the last child of the returned fragment - immediately after the `{selectedProduct && (<ProductModal product={selectedProduct} onClose={handleCloseModal} onAddToCart={addToCart} />)}` block and before the closing `</>` - the exact markup `<footer><p><em>Built by the Dark Factory - by the Developer Agent</em></p></footer>`. Copy the string verbatim: plain ASCII hyphen with one space either side, capitals 'Dark Factory' and 'Developer Agent'. Add no className, no style prop, no imports and no other change anywhere; `<em>` alone supplies the italics.
6. Run: npx vitest run src/pages/HomePage.test.jsx. Expected: PASS (2 tests).
7. Commit: git add src/pages/HomePage.jsx src/pages/HomePage.test.jsx && git commit -m "feat: add Dark Factory credit to home page footer"

**Verification:** npx vitest run src/pages/HomePage.test.jsx - both tests pass, and `git diff --stat` shows only src/pages/HomePage.jsx modified and src/pages/HomePage.test.jsx added.

### 2. Lock the scope: credit appears once and nothing else on the home page changed

**Objective:** Guard rails that the new line is additive only - exactly one occurrence on the home page, existing home page content still rendered, no regressions in the rest of the suite, and the credit present in the prerendered static HTML.

**Files:** `src/pages/HomePage.test.jsx`

**Steps:**

1. Add to the same suite, still in src/pages/HomePage.test.jsx: 'renders the credit exactly once alongside the unchanged All Items heading' - render the harness, expect(screen.getAllByText('Built by the Dark Factory - by the Developer Agent')).toHaveLength(1) and expect(screen.getByText('All Items')).toBeDefined(). The heading assertion proves the h2 that HomePage already rendered (text node 'All Items' with the product-count span beside it) is untouched; 'All Items' resolves to that h2 because CategoryFilter does not render with categories: [].
2. Run: npx vitest run src/pages/HomePage.test.jsx. Expected: PASS (3 tests).
3. Run the whole unit suite: npx vitest run. Expected: PASS - no component, page or hook suite regressed, proving the change is confined to the home page route component.
4. Run: npm run build:prerender, then grep -c "Built by the Dark Factory - by the Developer Agent" dist/index.html. Expected: 1 - scripts/prerender.mjs renders the '/' route into dist/index.html, so the credit must be present in the static HTML (the script falls back to an empty product list when Wix is not configured, and HomePage renders the credit in that empty state too).
5. Commit: git add src/pages/HomePage.test.jsx && git commit -m "test: pin home page Dark Factory credit scope"

**Verification:** npx vitest run (whole suite green) and, after npm run build:prerender, grep -c "Built by the Dark Factory - by the Developer Agent" dist/index.html returns exactly 1.
