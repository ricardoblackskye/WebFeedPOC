# Plan: DF Test issue for #770

Story: #273
Issue: [#273](https://github.com/ricardoblackskye/webfeedpoc/issues/273)

## Goal

Add one italic credit line — 'Built by the Dark Factory - by the Developer Agent' — to the site footer that the App shell renders, immediately alongside the existing copyright notice. The footer markup lives in src/App.jsx (the route shell), so the change is a single JSX line, plus coverage added to the existing co-located spec src/App.test.jsx (which already exists in the repository and is therefore modified, not created). No new components, no CSS changes, no data-flow changes, and no changes to any page component.

## Approach

The page footer is not owned by the home page: HomePage.jsx (route '/') renders filters, product grid, pagination and the product modal, and stops there. The bottom-of-page markup is composed by the application shell, src/App.jsx (role: shell, evidence: 'renders an outlet, so it is rendered on every route'), which ends with `<footer className="app-footer"><p>&copy; {new Date().getFullYear()} {SITE_NAME}. All rights reserved.</p></footer>`. That element is therefore the only existing place that matches the story's 'next to the copyright text at the bottom of the page', and it is reached by the home page through the Outlet at route '/' in both src/main.jsx (client) and src/entry-server.jsx (prerender). The implementation keeps the copyright paragraph byte-for-byte as it is today and appends one sibling paragraph containing `<em>Built by the Dark Factory - by the Developer Agent</em>`. Italics are expressed semantically with `<em>` rather than a new class plus a rule in App.css: that satisfies the visual requirement, survives jsdom (which applies no stylesheets), and honours 'No other changes' by not touching stylesheets. Because the footer belongs to the shared shell, the line also appears on the other routes; that is inherent to where the footer is composed and is not treated as scope creep, and it still satisfies 'on the home page'. Prerendering needs no edit — scripts/prerender.mjs renders the same App through src/entry-server.jsx, so the new line lands in the generated static HTML automatically. Verification extends the already-present shell spec at src/App.test.jsx (a sibling `*.test.jsx` per file under test, exactly as src/components/Cart.test.jsx and src/components/CategoryFilter.test.jsx demonstrate). Because that spec already exists, the work there is additive: keep every existing test and mock, then append a new describe block that renders App inside HelmetProvider and a MemoryRouter with a single '/' route, reusing (or, if absent, adding) mocks for ./hooks/useWixProducts and ./hooks/useWixCart so no network or Wix client is touched, and asserting the exact string, its `<em>` tag, and that the string and the pre-existing copyright text share the `footer.app-footer` element.

## Tasks

### 1. Add the italic Dark Factory footer line to the site footer (src/App.jsx) and extend the existing shell spec (src/App.test.jsx)

**Objective:** Render the exact text 'Built by the Dark Factory - by the Developer Agent' in italics in the existing `footer.app-footer` element, directly next to the copyright notice, leaving every other part of the footer and every other file untouched; add the assertions to the existing src/App.test.jsx without disturbing its current tests.

**Files:** `src/App.jsx`, `src/App.test.jsx`

**Steps:**

1. Open the existing `src/App.test.jsx` (it is already in the repository) and read it end to end. Keep every existing `describe`/`it` block, import and mock exactly as it is; this task is additive only.
2. Confirm the file mocks the two hooks App consumes. If `vi.mock('./hooks/useWixProducts', ...)` and `vi.mock('./hooks/useWixCart', ...)` are already present, reuse them as-is. If either is missing, add it at the top level of the file (Vitest hoists `vi.mock` calls) with the shapes App reads: `{ products: [], loading: false, error: null, refreshing: false }` for `useWixProducts`, and `{ cart: [], loading: false, error: null, useWixBackend: false, addToCart: vi.fn(), removeFromCart: vi.fn(), updateQuantity: vi.fn(), totals: { subtotal: 0, discount: 0, shipping: 0, tax: 0, total: 0 } }` for `useWixCart` — so rendering App performs no fetch and no Wix call.
3. Reuse the file's existing render helper if it has one (render App inside `HelmetProvider` and a `MemoryRouter`); otherwise add a local `renderApp()` helper that renders `<HelmetProvider><MemoryRouter initialEntries={['/']}><Routes><Route path="/" element={<App />} /></Routes></MemoryRouter></HelmetProvider>` and returns the RTL result. This mirrors the client route table in src/main.jsx, where App is the element for '/' and HomePage is its index child.
4. Append a new `describe('Dark Factory footer credit', ...)` block containing the failing test `renders the Dark Factory footer line on the home page`: call the render helper, then `expect(screen.getByText('Built by the Dark Factory - by the Developer Agent')).toBeDefined()`. The string must be copied verbatim from the story, including the single spaces around the plain hyphen-minus.
5. In the same describe block add the failing test `renders the Dark Factory footer line in italics (em element)`: `const line = screen.getByText('Built by the Dark Factory - by the Developer Agent')`, then `expect(line.tagName).toBe('EM')` — jsdom applies no stylesheets, so italics are asserted through the semantic tag rather than a computed font-style.
6. In the same describe block add the failing test `renders the Dark Factory line next to the copyright notice inside the site footer`: `const footer = container.querySelector('footer.app-footer')` must not be null, and `footer.textContent` must contain `'Built by the Dark Factory - by the Developer Agent'`, `'All rights reserved.'` and `String(new Date().getFullYear())` — this proves the new line sits inside the same footer element as the copyright rather than somewhere else on the page.
7. In the same describe block add the failing test `keeps the existing copyright notice unchanged`: assert `container.querySelector('footer.app-footer').querySelectorAll('p').length === 2` and that the first paragraph's text matches `/^©\s*\d{4}\s+.*All rights reserved\.$/` — this pins that the copyright paragraph was added to, not rewritten, and that no third footer block appeared.
8. Run `npx vitest run src/App.test.jsx`. Expected: the four new tests FAIL with 'Unable to find an element with the text: Built by the Dark Factory - by the Developer Agent' (and the `em`/footer assertions failing on the same missing node), while every pre-existing test in the file still passes.
9. In `src/App.jsx`, inside the existing `<footer className="app-footer">`, leave `<p>&copy; {new Date().getFullYear()} {SITE_NAME}. All rights reserved.</p>` exactly as written today and add directly after it: `<p className="footer-built-by"><em>Built by the Dark Factory - by the Developer Agent</em></p>`. Use `<em>` so the line is italic without adding any rule to src/App.css, and add no other markup, props, imports or logic.
10. Run `npx vitest run src/App.test.jsx`. Expected: all pre-existing tests plus the four new tests PASS. If (and only if) a pre-existing test asserted on the exact footer contents, amend that single assertion minimally to include the new line rather than weakening or deleting it.
11. Run `npm test` and `npm run lint`. Expected: the full Vitest suite is green (no regression in the existing component specs) and ESLint reports no new problems.
12. Commit the two files: `git add src/App.jsx src/App.test.jsx && git commit -m "feat: add Dark Factory credit line to site footer"`.

**Verification:** `npx vitest run src/App.test.jsx` → all pre-existing tests plus the 4 new tests passing; `npm test` → whole suite green; `npm run lint` → clean; manual check with `npm run dev` on `/` shows the italic line 'Built by the Dark Factory - by the Developer Agent' immediately below '© `<year>` Antiques Marketplace. All rights reserved.' in the footer, with no other visual difference.
