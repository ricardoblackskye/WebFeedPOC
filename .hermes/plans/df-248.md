# Plan: Test issue for the Dark Factory

Story: #248
Issue: [#248](https://github.com/ricardoblackskye/webfeedpoc/issues/248)

## Goal

Add one italic credit line — 'Built by the Dark Factory - by the Developer Agent' — at the bottom of the home page only. The line is rendered inside the existing home page component (src/pages/HomePage.jsx, the component bound to the '/' index route), as a semantic `<footer> containing <p><em>…</em></p>, so italics come from the <em>` element and no stylesheet is touched. The site-wide footer owned by src/App.jsx (the copyright line rendered on every route) is deliberately left alone, because editing it would leak the credit onto product, category, about and architecture pages. A new colocated unit test renders HomePage with the outlet context that App supplies and pins both the exact copy/italic semantics and the unchanged existing home page content.

## Approach

Why this file: REPOSITORY EVIDENCE for src/entry-server.jsx shows the route table binding the index route to HomePage (<Route path="/" element={`<App initialProducts={data.products} />`}> with <Route index element={`<HomePage />`} />), and src/main.jsx wires the same index route in the browser. So src/pages/HomePage.jsx IS the home page, and it is the UI entry point the evidence names. src/App.jsx also has a `<footer className="app-footer"> with the copyright line, but App renders the shell (header, nav, cart drawer) on every route, so putting the credit there would violate 'home page' and 'No other changes'. Why no CSS: the story asks for italics and nothing else; a <em> element is italic by default, so no stylesheet, class or theme variable is introduced. Why no other component: HomePage currently imports ProductList, CategoryFilter, SortControls, Pagination and ProductModal purely to compose the catalogue, none of which is a page-level footer. Shape of the change: inside the fragment returned by HomePage, after the {selectedProduct && (<ProductModal … />)} block, append <footer><p><em>Built by the Dark Factory - by the Developer Agent</em></p></footer>. The copy is reproduced byte-for-byte from the story (plain ASCII hyphen surrounded by single spaces). Placement at the very end of the fragment guarantees it renders below the product grid, pagination and any product modal on the '/' route and on no other route. Proof: a new colocated test file, src/pages/HomePage.test.jsx, mirrors the repository's existing colocated *.test.jsx convention (see src/components/Cart.test.jsx) and mounts HomePage the way the app does — a data router (createMemoryRouter, react-router-dom v7) whose parent route is <Outlet context={…}/> carrying the same outlet context keys App passes (products, loading, error, categories, productCounts, addToCart), wrapped in HelmetProvider. Because HomePage's Helmet block only renders when itemListSchema exists, the test drives an empty product list, which also exercises the existing 'No products available' branch and proves no existing home page output was disturbed. The test asserts the exact credit text, that the text node's element is an EM (the italic semantic), that it sits inside a <footer>`, and that the pre-existing 'All Items' heading and empty-state message still render. Verification order: the new test first (red), then the one-line implementation, then the file's test green, then the whole vitest suite plus lint and typecheck to prove nothing else moved.

### 1. Add the italic Dark Factory credit line to the home page footer

**Objective:** Render the exact line 'Built by the Dark Factory - by the Developer Agent' in italics at the end of the home page output only (route '/'), proven by a new colocated unit test that mounts HomePage with the outlet context App supplies.

**Files:** `src/pages/HomePage.jsx`, `src/pages/HomePage.test.jsx`

**Steps:**

1. Create the failing test at src/pages/HomePage.test.jsx with exactly this content:

import { describe, it, expect, vi } from 'vitest'
import { render, screen } from '@testing-library/react'
import { createMemoryRouter, RouterProvider, Outlet } from 'react-router-dom'
import { HelmetProvider } from 'react-helmet-async'
import HomePage from './HomePage'

const outletContext = {
  products: [],
  loading: false,
  error: null,
  categories: [],
  productCounts: { All: 0 },
  addToCart: vi.fn(),
}

function renderHomePage() {
  const router = createMemoryRouter(
    [
      {
        path: '/',
        element: `<Outlet context={outletContext} />`,
        children: [{ index: true, element: `<HomePage />` }],
      },
    ],
    { initialEntries: ['/'] }
  )
  return render(
    `<HelmetProvider>`
      `<RouterProvider router={router} />`
    `</HelmetProvider>`
  )
}

describe('HomePage', () => {
  it('renders the Dark Factory credit in italics on the home page', () => {
    renderHomePage()
    const credit = screen.getByText('Built by the Dark Factory - by the Developer Agent')
    expect(credit).toBeDefined()
    expect(credit.tagName).toBe('EM')
    expect(credit.closest('footer')).not.toBeNull()
  })

  it('still renders the existing home page content unchanged', () => {
    renderHomePage()
    expect(screen.getByText(/All Items/)).toBeDefined()
    expect(screen.getByText('No products available')).toBeDefined()
  })
})
2. Run: npx vitest run src/pages/HomePage.test.jsx
Expected: FAIL — the 'renders the Dark Factory credit in italics on the home page' test fails with 'Unable to find an element with the text: Built by the Dark Factory - by the Developer Agent' (the 'still renders the existing home page content unchanged' test already passes, proving the mount harness is correct).
3. Implement in src/pages/HomePage.jsx: inside the fragment returned by HomePage (the one that starts with the {itemListSchema && (`<Helmet>…)} block), immediately after the {selectedProduct && (<ProductModal product={selectedProduct} onClose={handleCloseModal} onAddToCart={addToCart} />`)} block and before the closing </>, append:

      `<footer>`
        `<p><em>Built by the Dark Factory - by the Developer Agent</em></p>`
      `</footer>`

No other line of HomePage.jsx changes: no new imports, no new props, no CSS file, no stylesheet import.
4. Run: npx vitest run src/pages/HomePage.test.jsx
Expected: PASS — 2 tests passed.
5. Run the repository checks: npx vitest run (whole suite), npm run lint, npm run typecheck.
Expected: all green; the only diff is the footer block inside src/pages/HomePage.jsx plus the new src/pages/HomePage.test.jsx.
6. Commit: git add src/pages/HomePage.jsx src/pages/HomePage.test.jsx && git commit -m "feat(home): add Dark Factory credit line to home page footer"
