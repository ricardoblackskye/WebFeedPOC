# Plan: Test for dark factory issue #703

Story: #246
Issue: [#246](https://github.com/ricardoblackskye/webfeedpoc/issues/246)

## Goal

Add a single italic credit line, 'Built by the Dark Factory - by the Developer Agent', to the home page only. The home page is route '/' rendered by src/pages/HomePage.jsx, which returns one React fragment composed of CategoryFilter, a product-count heading, SortControls, ProductList, Pagination and ProductModal. The line is appended as the last child of that fragment, wrapped in a semantic `<em>` element for italics. No CSS, no new component, no new route, no new dependency, and no change to the app-level footer in src/App.jsx (which is the shell that renders the Outlet on every route). The change is proven by a colocated Vitest + Testing Library test that mounts HomePage under a MemoryRouter route tree supplying the outlet context HomePage consumes.

## Approach

The story asks for a footer line on the home page and nothing else. Two candidate locations exist and only one is correct. src/App.jsx owns the `<footer className="app-footer"> element, but its evidence role is 'shell' and it renders an Outlet, so it is mounted on every route (/products/:slug, /category/:categoryName, /about, /architecture, /orders, /releasenotes); editing it would put the line on every page and break 'no other changes'. The home page entry point the evidence names is src/pages/HomePage.jsx, whose route is '/' (src/entry-server.jsx and src/main.jsx both map the index route to it). HomePage already returns a single React fragment ending with the conditional ProductModal, so the credit line is inserted as the final child of that fragment: a <p> wrapping <em>Built by the Dark Factory - by the Developer Agent</em>. <em> is the semantic italics element and inherits the page typography, so no stylesheet edit is required and no existing CSS class is touched. The copy is used verbatim, ASCII hyphen included, matching the story text exactly. Because HomePage calls useOutletContext() and useSearchParams(), it cannot be rendered bare; the test harness mounts it inside a MemoryRouter whose parent route element renders <Outlet context={{ products: [], loading: false, error: null, categories: [], productCounts: { All: 0 }, addToCart: () =>` {} }} />, wrapped in HelmetProvider because HomePage renders a react-helmet-async `<Helmet> block. Three assertions pin the change: the exact copy is present, the element carrying it is an <em> (italics, not a CSS class), and it appears exactly once while the pre-existing 'All Items' heading and '(0)' product count still render. Scoping to the home page is enforced structurally by putting the JSX only in HomePage.jsx, and the test tree only ever mounts HomePage at the index route. Prerendering needs no extra work: scripts/prerender.mjs imports src/entry-server.jsx, which renders HomePage for '/', so the line appears in dist/index.html with the rest of the page. Failure modes deliberately covered by the tests: exact copy drift (em dash or smart quotes instead of the ASCII hyphen), italics implemented as a CSS class or <i> instead of the semantic <em>`, the line being duplicated by a re-render, and regression of the existing home page heading/count markup. Not covered by unit tests and therefore checked manually: the line must not appear on non-home routes.

## Tasks

### 1. Add the italic Dark Factory credit line to the home page

**Objective:** Render 'Built by the Dark Factory - by the Developer Agent' inside an `<em>` element as the last child of HomePage's returned fragment, proven by a colocated Vitest test, with no other file, style, route or dependency changes.

**Files:** `src/pages/HomePage.jsx`, `src/pages/HomePage.test.jsx`

**Steps:**

1. Create src/pages/HomePage.test.jsx (colocated Vitest + Testing Library test, matching the *.test.jsx pattern used by src/components/*.test.jsx). Harness: import { describe, it, expect } from 'vitest'; import { render, screen } from '@testing-library/react'; import { MemoryRouter, Routes, Route, Outlet } from 'react-router-dom'; import { HelmetProvider } from 'react-helmet-async'; import HomePage from './HomePage'. Define const CREDIT_LINE = 'Built by the Dark Factory - by the Developer Agent' and const outletContext = { products: [], loading: false, error: null, categories: [], productCounts: { All: 0 }, addToCart: () => {} }. Define function ContextRoute() { return `<Outlet context={outletContext} /> } and function renderHomePage() { return render(<HelmetProvider><MemoryRouter initialEntries={['/']}><Routes>`<Route element={`<ContextRoute />`}><Route index element={`<HomePage />`} />`</Route></Routes></MemoryRouter></HelmetProvider>`) }. Then three tests inside describe('HomePage'): (1) it('renders the Dark Factory credit line with the exact copy on the home page') -> renderHomePage(); expect(screen.getByText(CREDIT_LINE)).toBeDefined(). (2) it('renders the Dark Factory credit line in italics') -> renderHomePage(); const line = screen.getByText(CREDIT_LINE); expect(line.tagName).toBe('EM'). (3) it('renders the credit line once alongside the existing home page heading and product count') -> renderHomePage(); expect(screen.getAllByText(CREDIT_LINE)).toHaveLength(1); expect(screen.getByRole('heading', { name: /All Items/ })).toBeDefined(); expect(screen.getByText('(0)')).toBeDefined().
2. Run: npx vitest run src/pages/HomePage.test.jsx. Expected: FAIL on tests 1-3 with 'Unable to find an element with the text: Built by the Dark Factory - by the Developer Agent' (the harness itself must render without errors, otherwise fix the outlet context keys before continuing).
3. Edit src/pages/HomePage.jsx: inside the returned fragment, after the closing of the {selectedProduct && (`<ProductModal ... />`)} block and before the final </>, add exactly: `<p><em>Built by the Dark Factory - by the Developer Agent</em></p>. Use the plain ASCII hyphen from the story copy, use <em> (not <i>`, not a CSS class), and change nothing else in the file - no new imports, no className, no stylesheet.
4. Run: npx vitest run src/pages/HomePage.test.jsx. Expected: PASS, 3 tests passed.
5. Run the full unit suite and linter: npm test -- --run and npm run lint. Expected: all previously passing suites still pass and no new lint errors (eslint.config.js lints src/**/*.jsx and declares the vitest globals describe/it/expect).
6. Manual scope check: npm run dev, open `http://localhost:5173/` and confirm the italic line renders at the bottom of the home page; open `http://localhost:5173/architecture` and `http://localhost:5173/about` and confirm the line is absent and the existing app footer text is unchanged.
7. Commit: git add src/pages/HomePage.jsx src/pages/HomePage.test.jsx && git commit -m "feat: add Dark Factory credit line to home page"

**Verification:** npx vitest run src/pages/HomePage.test.jsx passes all three cases (exact copy present, element is `<em>`, rendered exactly once with the existing 'All Items' heading and '(0)' count intact); npm test -- --run and npm run lint are clean; manual check confirms the line appears on '/' only and the app-level footer in src/App.jsx is untouched.
