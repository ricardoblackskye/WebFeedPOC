# Plan: Test Issues for dark factory task #665

Story: #226
Issue: [#226](https://github.com/ricardoblackskye/webfeedpoc/issues/226)

## Goal

A single additive, presentational change: src/pages/HomePage.jsx — the page component that src/entry-server.jsx and src/main.jsx map to route '/' — gains one trailing footer line rendered below the ProductList/Pagination block: <p><em>Built by the Dark Factory - by the Developer Agent</em></p>. No props, state, routing, data-fetching or CSS changes are made, and the site-wide footer owned by the App shell (src/App.jsx, <footer className="app-footer">) is left untouched so the line appears on the home page only. Coverage is added in a HomePage component test (src/pages/HomePage.test.jsx) plus a home-page-only guard test in the existing src/components/ProductList.test.jsx suite.

## Approach

The home page is composed in src/pages/HomePage.jsx. That component consumes the outlet context `{ products, loading, error, categories, productCounts, addToCart }` provided by src/App.jsx and renders, in order: CategoryFilter, an <h2> product-count heading, SortControls, then the ProductList + Pagination block (or an empty/error state), then ProductModal for the selected item. The story asks for a footer line below the main list of products on the home page, in italics, with no other changes. Therefore the change is confined to the tail of HomePage's returned fragment: a plain <p> wrapping an <em> whose text is exactly 'Built by the Dark Factory - by the Developer Agent' (the literal copy from the story, with the plain hyphen). It is placed after the product list / pagination / empty-state blocks and before the conditional ProductModal, so it renders last on the page and below the product list in document order. We deliberately do not touch the App shell's <footer className="app-footer"> because that footer is rendered by the App route on every route (products, category, architecture, about, releasenotes), which would violate 'home page' and 'no other changes'. No CSS file is added: <em> carries the italic semantics the story asks for, and adding a stylesheet rule would be an extra, unrequested change. No state, props, hooks or data flow change, so the change is SSR-safe for the prerender path (scripts/prerender.mjs renders HomePage through src/entry-server.jsx, where a static element is harmless). Verification follows TDD: a new component test renders HomePage inside the same outlet-context contract App uses (MemoryRouter + a parent route rendering <Outlet context={...}/> + HelmetProvider), asserts the exact copy is present, asserts the text node is inside an <em> element, and asserts document-order placement below the rendered product name using compareDocumentPosition. A second, negative guard test in the existing ProductList.test.jsx suite renders ProductList directly and asserts the footer copy is absent, pinning the 'home-page only / no other components changed' constraint. Both suites, the full Vitest run and ESLint gate each commit.

**Steps:**

1. Step 1 - Write the failing test. Add a new test file `src/pages/HomePage.test.jsx` (create it if it does not exist; if it already exists, append a `describe('HomePage built-by footer', ...)` block and reuse its existing render helper). The harness must satisfy HomePage's `useOutletContext()` dependency from src/App.jsx, its `useSearchParams()` dependency from react-router-dom and its Helmet usage:

```jsx
import { describe, it, expect, vi } from 'vitest'
import { render, screen } from '@testing-library/react'
import { MemoryRouter, Outlet, Route, Routes } from 'react-router-dom'
import { HelmetProvider } from 'react-helmet-async'
import HomePage from './HomePage'

const FOOTER_TEXT = 'Built by the Dark Factory - by the Developer Agent'

const products = [
  {
    id: 'p1',
    name: 'Victorian Oak Chair',
    price: 250,
    category: 'Furniture',
    description: 'A sturdy Victorian oak chair',
    image: 'chair.jpg',
  },
]

function renderHomePage(items = products) {
  const context = {
    products: items,
    loading: false,
    error: null,
    categories: ['Furniture'],
    productCounts: { All: items.length, Furniture: items.length },
    addToCart: vi.fn(),
  }

  return render(
    <HelmetProvider>
      <MemoryRouter initialEntries={['/']}>
        <Routes>
          <Route path="/" element={<Outlet context={context} />}>
            <Route index element={<HomePage />} />
          </Route>
        </Routes>
      </MemoryRouter>
    </HelmetProvider>
  )
}

describe('HomePage built-by footer', () => {
  it('renders the built-by footer line on the home page', () => {
    renderHomePage()
    expect(screen.getByText(FOOTER_TEXT)).toBeDefined()
  })

  it('renders the built-by footer text inside an em element', () => {
    renderHomePage()
    expect(screen.getByText(FOOTER_TEXT).tagName).toBe('EM')
  })

  it('renders the built-by footer below the product list', () => {
    renderHomePage()
    const footer = screen.getByText(FOOTER_TEXT)
    const listedProduct = screen.getByText('Victorian Oak Chair')
    const position = listedProduct.compareDocumentPosition(footer)
    expect(position & Node.DOCUMENT_POSITION_FOLLOWING).toBeTruthy()
  })
})
```

Only the copy string is fixed by the story; keep it byte-for-byte including the plain hyphen.
