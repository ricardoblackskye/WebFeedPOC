# Plan: Dark Factory test issue

Story: #271
Issue: [#271](https://github.com/ricardoblackskye/webfeedpoc/issues/271)

## Goal

Add a single italic credit line — 'Built by the Dark Factory - by the Developer Agent' — directly beside the existing copyright text in the site footer. The copyright notice lives in exactly one place in the repository: the `<footer className="app-footer"> block of src/App.jsx, the shell component that renders the route <Outlet/> and is composed by both src/main.jsx (client) and src/entry-server.jsx (prerender). The change is JSX-only: a new paragraph containing a semantic <em> element placed immediately after the copyright paragraph inside that same footer. No stylesheet, route, data-fetch or component-contract changes; italics come from the <em>` element itself, so src/App.css is untouched. A new colocated Vitest + React Testing Library test (src/App.test.jsx) pins the copy, the italics and the unchanged copyright line.

## Approach

Discovery: the story anchors placement to 'the copyright text at the bottom of the page'. The evidence shows the only copyright text in the repository is the paragraph inside `<footer className="app-footer"> in src/App.jsx (role: 'shell' — it renders an <Outlet/>`, so it wraps every route, and it is the file mounted by src/main.jsx's BrowserRouter Route path="/" and by src/entry-server.jsx when prerendering). No page component owns a footer: src/pages/HomePage.jsx (route '/') renders only the category filter, count heading, sort controls, product list, pagination and modals, and src/components/OrderConfirmation.css's .order-footer belongs to the order-confirmation surface, not the home page. Therefore the correct target is src/App.jsx.

Change: inside `<footer className="app-footer">, immediately after the existing copyright paragraph (<p>© {new Date().getFullYear()} {SITE_NAME}. All rights reserved.</p>), add a sibling paragraph <p className="app-footer-credit"><em>Built by the Dark Factory - by the Developer Agent</em></p>. The copyright paragraph is left byte-identical — no text, spacing or attribute edits — so the diff is purely additive and matches 'no other changes'. The literal string uses a spaced ASCII hyphen exactly as written in the story (not an en dash, not a hyphen without spaces). Italics are delivered by the semantic <em>` element's user-agent style rather than a new CSS rule, which keeps the change to one file and avoids touching src/App.css; adding a class name keeps a hook available without committing to styling.

Interpretation of 'footer line to the home page': the footer is a shared shell element, so the new line renders on every route that is wrapped by App, including '/'. Making it home-only would require route-conditional logic (useLocation + pathname check) in the shell, which is a larger behavioural change than the story's 'no other changes' allows and would break the requested adjacency to the copyright text on the other pages. This trade-off is recorded here so the reviewer can accept it or ask for a follow-up gate on useLocation().pathname === '/'.

Testing: the repo's convention is colocated tests (src/components/Cart.test.jsx beside src/components/Cart.jsx). A new src/App.test.jsx renders App inside HelmetProvider + MemoryRouter (App uses Helmet, Link and Outlet) with the two data hooks mocked — ./hooks/useWixProducts returning an empty, non-loading product set and ./hooks/useWixCart returning an empty cart with a zeroed totals object — so no network, Wix SDK or cart state is required. The tests assert (a) the footer contains both the copyright text and the exact new string, (b) the new string is wrapped in an `<em>` element, and (c) the existing copyright line is unchanged, which is the regression guard for 'no other changes'. Because App is also the SSR entry, a final verification task prerenders and greps dist/index.html to prove the line survives the static-HTML path.

## Tasks

### 1. Render the Dark Factory credit line in the app footer

**Objective:** Add the italic line 'Built by the Dark Factory - by the Developer Agent' next to the copyright text inside the .app-footer of the App shell, driven by a failing-to-passing colocated unit test.

**Files:** `src/App.test.jsx`, `src/App.jsx`

**Steps:**

1. Create src/App.test.jsx. Mock the shell's data hooks with vi.mock('./hooks/useWixProducts', () => ({ useWixProducts: () => ({ products: [], loading: false, error: null, refreshing: false }) })) and vi.mock('./hooks/useWixCart', () => ({ useWixCart: () => ({ cart: [], loading: false, error: null, useWixBackend: false, addToCart: vi.fn(), removeFromCart: vi.fn(), updateQuantity: vi.fn(), totals: { subtotal: 0, discount: 0, shipping: 0, tax: 0, total: 0 } }) })). Add a helper renderApp() that renders `<HelmetProvider><MemoryRouter initialEntries={['/']}><App /></MemoryRouter></HelmetProvider>` (Helmet needs a provider; Link needs a router).
2. Add test 'renders the Dark Factory credit line in the footer with the copyright text': const footer = container.querySelector('.app-footer'); expect(footer).not.toBeNull(); expect(footer).toHaveTextContent(/All rights reserved\./); expect(footer).toHaveTextContent('Built by the Dark Factory - by the Developer Agent').
3. Add test 'renders the Dark Factory credit line inside an `<em>` element (italic)': const credit = container.querySelector('.app-footer em'); expect(credit).not.toBeNull(); expect(credit.textContent).toBe('Built by the Dark Factory - by the Developer Agent').
4. Add test 'leaves the existing copyright line unchanged in the footer': const copyright = container.querySelector('.app-footer > p'); expect(copyright.textContent).toMatch(/^© \d{4} .+ All rights reserved\.$/).
5. Run: npx vitest run src/App.test.jsx — Expected: FAIL — the two credit-line tests fail because '.app-footer em' resolves to null and the footer text content does not contain the new string; the copyright test passes.
6. Modify src/App.jsx: inside `<footer className="app-footer">, immediately after the existing copyright paragraph, add <p className="app-footer-credit"><em>Built by the Dark Factory - by the Developer Agent</em></p>`. Do not edit the copyright paragraph, do not add CSS, do not import anything new.
7. Run: npx vitest run src/App.test.jsx — Expected: PASS (3 tests).
8. Run: npx vitest run and npm run lint — Expected: the full unit suite and ESLint pass with no new warnings.
9. Commit: git add src/App.jsx src/App.test.jsx && git commit -m "feat: add Dark Factory credit line to footer"

**Verification:** npx vitest run src/App.test.jsx reports 3 passing tests, in particular that '.app-footer em' has textContent exactly 'Built by the Dark Factory - by the Developer Agent' and that the copyright paragraph still matches /^© \d{4} .+ All rights reserved\.$/. The full suite (npx vitest run) and npm run lint must also pass.

### 2. Verify the line survives prerendering and that no other files changed

**Objective:** Prove the footer line is present in the statically prerendered HTML for the home route (App is the SSR shell) and confirm the diff touches only the two intended files.

**Files:** `src/App.jsx`, `src/App.test.jsx`

**Steps:**

1. Run: git status --short && git diff --stat HEAD~1 — Expected: only src/App.jsx (modified) and src/App.test.jsx (added); no stylesheet, route table, hook or page file appears.
2. Run: npm run build:prerender — Expected: the script finishes with 'Prerendering complete'. A warning that Wix products could not be fetched is acceptable (the script continues with an empty product list).
3. Run: grep -c 'Built by the Dark Factory - by the Developer Agent' dist/index.html — Expected: at least 1, and the surrounding markup shows the string inside an `<em>` element within the app-footer paragraph, confirming the client and prerender paths agree.
4. Run: npm run dev and open `http://localhost:5173/` — Expected: at the bottom of the page the italic line appears next to the copyright text, and the copyright text is otherwise unchanged.

**Verification:** dist/index.html (the prerendered '/' route produced by scripts/prerender.mjs through src/entry-server.jsx) contains the exact string inside an `<em>` within the app footer, and git shows the change limited to src/App.jsx plus the new src/App.test.jsx.
