# Plan: DF Test for issue 742

Story: #258
Issue: [#258](https://github.com/ricardoblackskye/webfeedpoc/issues/258)

## Goal

Add a single static footer line, 'Built by the Dark Factory - by the Developer Agent', rendered in italics at the end of the home page only. The change is confined to the React component that owns the '/' route (src/pages/HomePage.jsx) plus one colocated Vitest/React Testing Library suite that pins the exact copy and the italic emphasis. No CSS, routing, data-fetching, SSR, or shared-shell changes are made: the global footer in the App shell (src/App.jsx) is deliberately left untouched because that component renders an Outlet on every route.

## Approach

The home page surface is the component the route table names for '/': src/entry-server.jsx declares <Route path="/" element={`<App/>`}> with <Route index element={`<HomePage/>`} />, and src/main.jsx mirrors that table in the browser. src/pages/HomePage.jsx is therefore the correct owner of a home-page-only visual addition. The App shell (src/App.jsx) also renders a `<footer className="app-footer">, but its evidence note states it "renders an outlet, so it is rendered on every route"; adding the line there would change product, category, about, orders and architecture pages, which the story explicitly forbids ("No other changes"). So the line goes into HomePage's returned fragment, immediately after the trailing {selectedProduct && <ProductModal .../>} block, as a <footer className="home-footer"> containing a <p> whose only child is <em>Built by the Dark Factory - by the Developer Agent</em>. Italics are supplied by the semantic <em>` element's default emphasis rendering, so no stylesheet is added or modified - satisfying the literal "no other changes" constraint while keeping the copy in one place. The exact copy is preserved verbatim from the story, including the ASCII hyphen-minus with single spaces around it and no trailing punctuation. Because HomePage is prerendered by scripts/prerender.mjs, the line will also appear in the generated static HTML for '/', which is the desired behaviour and requires no change to that script. Tests are written first in a new colocated src/pages/HomePage.test.jsx (the repository pairs each component with a .test.jsx sibling, e.g. CategoryFilter.test.jsx beside CategoryFilter.jsx) using Vitest and React Testing Library: react-router-dom's useOutletContext and useSearchParams are mocked so the page can mount without a Router or the App layout, and the context supplies products: [] so the Helmet-based JSON-LD block and all child components (ProductList, Pagination, CategoryFilter, SortControls, ProductModal) stay unmounted, making the assertion deterministic. Three cases are pinned: the footer element exists with the exact text, the text node is an EM element (italic emphasis), and the pre-existing home page content (the "All Items" heading and the "No products available" notice) still renders unchanged.

import { describe, it, expect, vi } from 'vitest'
import { render, screen } from '@testing-library/react'
import HomePage from './HomePage'

vi.mock('react-router-dom', async (importOriginal) => {
  const actual = await importOriginal()
  return {
    ...actual,
    useOutletContext: () => ({
      products: [],
      loading: false,
      error: null,
      categories: [],
      productCounts: { All: 0 },
      addToCart: vi.fn(),
    }),
    useSearchParams: () => [new URLSearchParams(), vi.fn()],
  }
})

describe('HomePage footer line', () => {
  it('renders the Dark Factory footer line on the home page', () => {
    const { container } = render(`<HomePage />`)
    const footer = container.querySelector('footer.home-footer')
    expect(footer).not.toBeNull()
    expect(footer.textContent.trim()).toBe('Built by the Dark Factory - by the Developer Agent')
  })

  it('renders the footer line in italics', () => {
    render(`<HomePage />`)
    const line = screen.getByText('Built by the Dark Factory - by the Developer Agent')
    expect(line.tagName).toBe('EM')
  })

  it('keeps the rest of the home page unchanged', () => {
    render(`<HomePage />`)
    expect(screen.getByRole('heading', { name: /All Items/i })).toBeDefined()
    expect(screen.getByText('No products available')).toBeDefined()
  })
})
