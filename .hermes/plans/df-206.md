# Plan: Test issue for Developer Agent #657

Story: #206
Issue: [#206](https://github.com/ricardoblackskye/webfeedpoc/issues/206)

## Goal

Append one unconditional italic footer line ('Built by the Dark Factory - by the Developer Agent') to the home page component at route '/' (src/pages/HomePage.jsx) and pin it with a new co-located unit test (src/pages/HomePage.test.jsx). No stylesheet, route, config, dependency or shell change: italics come from the semantic <em> element, and the app shell footer in src/App.jsx is deliberately left untouched so the line stays scoped to the home page.

## Approach

The home page is the component bound to route '/': src/pages/HomePage.jsx is the `index` element nested under the App shell route in both src/main.jsx (client) and src/entry-server.jsx (SSR/prerender). HomePage returns a fragment containing the category filter, sort controls, product list, pagination and product modal, and every one of those renders conditionally on loading / error / product state. The change appends exactly one more node to that fragment, after the `{selectedProduct && <ProductModal ... />}` block: a `<footer className="home-footer">` containing `<p><em>Built by the Dark Factory - by the Developer Agent</em></p>`. Because it sits outside every conditional branch it also renders while products are loading, when the catalogue is empty, when the demo/error banner is shown and when a ?search= query is active; because it is plain JSX with no browser-only APIs it is safe on the prerender path that renders every route server-side. Italics are supplied by the semantic <em> element, so no CSS file is created or edited and the copy is written verbatim with an ASCII hyphen-minus (no em dash, no smart quotes). The existing global footer (`.app-footer` with the copyright line) in src/App.jsx is intentionally not modified: the story scopes the line to the home page, and the shell renders on every route, so adding it there would leak the line onto product, category, about and architecture pages — a change beyond the story. A new co-located test file src/pages/HomePage.test.jsx drives the page through a MemoryRouter with a parent route that supplies the outlet context (HomePage takes no props; it reads products/loading/error/categories/productCounts/addToCart from useOutletContext) and asserts the exact copy, the <em> element, the single-instance requirement, and the loading / empty-catalogue / search-query states. Nothing else is touched: no new dependency, no config, no route entry.

### 1. Add the Dark Factory footer line to the home page (TDD)

**Objective:** Render the exact italic line 'Built by the Dark Factory - by the Developer Agent' as a footer on the home page (src/pages/HomePage.jsx, the component for route '/'), proven by a new co-located test, without touching any other file or behaviour.

**Files:** `src/pages/HomePage.jsx`, `src/pages/HomePage.test.jsx`

**Steps:**

1. Create `src/pages/HomePage.test.jsx` with the failing tests below. `HomePage` takes no props and reads its data from `useOutletContext()`, so the helper renders it inside a `MemoryRouter` whose parent route provides the outlet context, wrapped in `HelmetProvider` (HomePage renders `<Helmet>` whenever products exist).

```jsx
import { describe, it, expect } from 'vitest'
import { render, screen } from '@testing-library/react'
import { MemoryRouter, Outlet, Route, Routes } from 'react-router-dom'
import { HelmetProvider } from 'react-helmet-async'
import HomePage from './HomePage'

const FOOTER_TEXT = 'Built by the Dark Factory - by the Developer Agent'

function renderHomePage({ context = {}, url = '/' } = {}) {
  const outletContext = {
    products: [],
    loading: false,
    error: null,
    categories: [],
    productCounts: { All: 0 },
    addToCart: () => {},
    ...context,
  }

  return render(
    <HelmetProvider>
      <MemoryRouter initialEntries={[url]}>
        <Routes>
          <Route element={<Outlet context={outletContext} />}>
            <Route path="/" element={<HomePage />} />
          </Route>
        </Routes>
      </MemoryRouter>
    </HelmetProvider>
  )
}

describe('HomePage footer', () => {
  it('renders the Dark Factory footer line in italics', () => {
    renderHomePage()
    expect(screen.getByText(FOOTER_TEXT).tagName).toBe('EM')
  })

  it('renders the footer copy exactly once with ASCII hyphen', () => {
    renderHomePage()
    const matches = screen.getAllByText(FOOTER_TEXT)
    expect(matches).toHaveLength(1)
    expect(matches[0].textContent).toBe('Built by the Dark Factory - by the Developer Agent')
  })

  it('renders the footer line while products are loading', () => {
    renderHomePage({ context: { loading: true } })
    expect(screen.getByText(FOOTER_TEXT).tagName).toBe('EM')
  })

  it('renders the footer line when no products are available', () => {
    renderHomePage()
    expect(screen.getByText('No products available')).toBeDefined()
    expect(screen.getByText(FOOTER_TEXT).tagName).toBe('EM')
  })

  it('renders the footer line when a search query is present', () => {
    renderHomePage({ url: '/?search=chair' })
    expect(screen.getByText(FOOTER_TEXT).tagName).toBe('EM')
  })
})
```
