# Plan: Add Footer (local sandbox test)

Story: #224
Issue: [#224](https://github.com/ricardoblackskye/webfeedpoc/issues/224)

## Goal

Single-file UI addition: the home page route component (src/pages/HomePage.jsx, role=page for route '/') gains one italic footer line — 'Built by the Dark Factory - by the Developer Agent' — rendered as the last content of its returned fragment, below the ProductList/Pagination block. No new components, no CSS, no data, routing or shell changes; the existing App-level footer and the shared ProductList component are left untouched. Covered by a new page-level Vitest/React Testing Library spec.

## Approach

The home page is the route '/' element: src/entry-server.jsx declares Route path="/" element={<App initialProducts={data.products} />} with Route index element={<HomePage />}, and src/main.jsx declares the same nesting, so the page-level UI that owns the product list is src/pages/HomePage.jsx (REPOSITORY EVIDENCE: role="page", evidence="route '/' -> src/pages/HomePage.jsx"). That component already composes CategoryFilter, SortControls, ProductList (the main list of products) and Pagination, followed by the loading/empty/error messages and the optional ProductModal. The change is one JSX block appended as the last content of the fragment HomePage() returns — after the {!loading && paginatedProducts.length > 0 && (<> <ProductList/> <Pagination/> </>)} block — rendering the exact string 'Built by the Dark Factory - by the Developer Agent' inside an <em> element, so the line is italic by browser default and no stylesheet has to be created or edited. The line is deliberately NOT added to src/components/ProductList.jsx, because that component is a shared list primitive (HomePage renders it and the category route reuses the same list), and NOT to src/App.jsx, whose existing <footer className="app-footer"> copyright block (role="shell", rendered on every route) is a different, site-wide footer; the story asks for the home page only and 'No other changes'. Verification is a new page-level spec, src/pages/HomePage.test.jsx, that renders HomePage inside a MemoryRouter with an Outlet context matching what src/App.jsx supplies (products, loading, error, categories, productCounts, addToCart), stubs ProductList and the structuredData helper so the test exercises page composition only, and asserts (a) the exact text, (b) that the element carrying the text is an EM (italics), (c) that it follows the product list in document order via compareDocumentPosition, and (d) that pre-existing home page content (the All Items heading and the product list) still renders.

## Tasks

### 1. Add the italic Dark Factory footer line below the product list on the home page

**Objective:** Render the exact text 'Built by the Dark Factory - by the Developer Agent' in italics as the last content of the home page fragment, below the product list and pagination, with no other change to the file or to any other file.

**Files:** `src/pages/HomePage.jsx`, `src/pages/HomePage.test.jsx`

**Steps:**

1. Write the failing spec: create `src/pages/HomePage.test.jsx`. At the top add `vi.mock('../components/ProductList', () => ({ default: () => <div data-testid="product-list" /> }))` and `vi.mock('../utils/structuredData', () => ({ generateItemListSchema: () => ({ '@type': 'ItemList' }) }))`, then `const products = [{ id: '1', name: 'Vase', description: 'A vase', price: 10, category: 'Ceramics' }]` and `const outletContext = { products, loading: false, error: null, categories: ['Ceramics'], productCounts: { All: 1, Ceramics: 1 }, addToCart: vi.fn() }`. Add a `renderHomePage()` helper that renders `<HelmetProvider><MemoryRouter initialEntries={['/']}><Routes><Route path="/" element={<Outlet context={outletContext} />}><Route index element={<HomePage />} /></Route></Routes></MemoryRouter></HelmetProvider>`. Add `describe('HomePage footer')` with four cases: 'renders the footer line with the exact credit text' — assert `screen.getByText('Built by the Dark Factory - by the Developer Agent')` is defined; 'renders the footer credit in italics using an em element' — assert that same element's `tagName` is `'EM'`; 'places the footer line after the product list in document order' — assert `screen.getByTestId('product-list').compareDocumentPosition(footer) & Node.DOCUMENT_POSITION_FOLLOWING` is truthy; 'keeps the existing home page content intact' — assert `screen.getByRole('heading', { level: 2 }).textContent` contains `All Items` and that `screen.getByTestId('product-list')` exists.
2. Run: `npx vitest run src/pages/HomePage.test.jsx` — expected FAIL: 'Unable to find an element with the text: Built by the Dark Factory - by the Developer Agent' (the italics and document-order assertions fail with the same error).
3. Implement in `src/pages/HomePage.jsx`: append one JSX block as the last content of the returned fragment — immediately after the `{!loading && paginatedProducts.length > 0 && (<> <ProductList ... /> <Pagination ... /> </>)}` block and the two empty-state `error` divs, and before the `{selectedProduct && (<ProductModal ... />)}` block — containing exactly `<p><em>Built by the Dark Factory - by the Developer Agent</em></p>`. Use `<em>` (browser-default italics) so no CSS file is created or modified, and change no other line of the file.
4. Run: `npx vitest run src/pages/HomePage.test.jsx` — expected PASS (4 tests).
5. Run: `npx vitest run` (whole unit suite) and `npm run lint` — expected PASS/clean, proving no other component test or lint rule regressed.
6. Commit: `git add src/pages/HomePage.jsx src/pages/HomePage.test.jsx && git commit -m "feat: add Dark Factory footer line to home page"`.

**Verification:** `npx vitest run src/pages/HomePage.test.jsx` passes all four footer tests (exact text, EM/italic element, document order after the product list, existing content intact); `npx vitest run` (full unit suite) and `npm run lint` stay green; `git diff --stat` shows only src/pages/HomePage.jsx modified plus the new src/pages/HomePage.test.jsx.
