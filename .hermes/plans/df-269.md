# Plan: Test issue for the Dark Factory - Footer Text

Story: #269
Issue: [#269](https://github.com/ricardoblackskye/webfeedpoc/issues/269)

## Goal

Append a single italic credit line — 'Built by the Dark Factory - by the Developer Agent' — to the existing site footer rendered by the application shell (src/App.jsx), immediately after the existing '© {year} Antiques Marketplace. All rights reserved.' sentence, and pin the exact copy, ordering and italic rendering with a new colocated unit test (src/App.test.jsx). No new components, no stylesheet changes and no other markup changes: the credit is added as an `<em> element inside the footer's existing <p>`, which is italic by default in every browser user-agent stylesheet.

## Approach

The footer is not a component of its own: the only place in the repository that renders a `<footer> is the application shell src/App.jsx (role='shell', imports useWixProducts/useWixCart, renders <Outlet/>, the header nav, the cart drawer and finally <footer className="app-footer"><p>&copy; {new Date().getFullYear()} {SITE_NAME}. All rights reserved.</p></footer>`). Because App is the element bound to route '/' (both in src/main.jsx's BrowserRouter and in src/entry-server.jsx's StaticRouter), the footer it renders IS the home page footer, so the story's 'footer section on the home page' is satisfied by editing that one block. The change is therefore purely additive and confined to a single JSX expression.

Design decisions the implementer cannot infer: (1) Place the credit as an `<em> element INSIDE the existing <p>, after the copyright text and separated by one explicit space ({' '}), rather than as a second <p>. The story says both 'after © 2026 Antiques Marketplace. All rights reserved.' and 'next to the text that is there already', so an inline sibling of the copyright sentence is the reading that satisfies both; it also keeps the source of truth for the anchor sentence in one node. (2) Use <em>` rather than a CSS class: it is the semantic emphasis element and browsers render it italic by default, so no change to src/App.css is needed and the 'no other changes' constraint holds. (3) Keep the dynamic {new Date().getFullYear()} — do NOT hardcode '2026'. The year renders as 2026 today, which matches the anchor text in the story verbatim, and hardcoding would be a behaviour change beyond the story. (4) Exact copy is fixed: 'Built by the Dark Factory - by the Developer Agent', with a spaced ASCII hyphen-minus (U+002D) and no trailing period.

Verification strategy: a new colocated test renders the shell in jsdom with its data hooks mocked (useWixProducts and useWixCart are mocked, and wixCheckoutService is mocked as Cart already does in src/components/Cart.test.jsx, so no Wix network or credentials are needed) inside HelmetProvider + MemoryRouter. The test asserts the credit text exists inside footer.app-footer, that its offset in the footer's textContent is strictly after the copyright sentence, that the element is an `<em>, and that the footer's full normalised text is exactly '<copyright sentence> <credit>`' — the last assertion is what enforces 'no other changes' to the footer. The interface between tasks is fixed by the constants COPYRIGHT (built from the exported SITE_NAME so it stays truthful if the year rolls over) and CREDIT.

Review focus (inputs/conditions the story implies but does not spell out): (a) the credit must appear exactly ONCE in the footer — a careless duplicate `<em>` or a copy into a second element would still pass a naive 'text is present' check; (b) the whitespace between the period and the credit must survive so the two read as one sentence; (c) the existing copyright sentence must still be findable by an exact-string query, which is why the trailing space lives in a {' '} text node rather than inside the copyright text node; (d) the year must remain dynamic so the anchor text keeps matching on 1 January; (e) nothing outside the footer may change — the mocked-hook render must still produce the header, the cart button and the empty-cart drawer.

## Tasks

### 1. Add the italic Dark Factory credit to the home page footer

**Objective:** The footer paragraph rendered by the app shell contains, after the copyright sentence and separated by a single space, an `<em>` element whose exact text is 'Built by the Dark Factory - by the Developer Agent'; the copy is unique in the footer and the copyright sentence is unchanged. Covered by three unit tests in src/App.test.jsx.

**Files:** `src/App.jsx`, `src/App.test.jsx`

**Steps:**

1. Write the failing test — create `src/App.test.jsx` with exactly this content:

```jsx
import { describe, it, expect, vi } from 'vitest'
import { render, screen } from '@testing-library/react'
import { MemoryRouter } from 'react-router-dom'
import { HelmetProvider } from 'react-helmet-async'
import App from './App'
import { SITE_NAME } from './utils/structuredData'

// The shell fetches products and cart state; mock the hooks so it renders in
// jsdom with no network and no Wix credentials (mirrors Cart.test.jsx, which
// mocks ../services/wixCheckoutService for the same reason).
vi.mock('./hooks/useWixProducts', () => ({
  useWixProducts: () => ({ products: [], loading: false, error: null, refreshing: false }),
}))
vi.mock('./hooks/useWixCart', () => ({
  useWixCart: () => ({
    cart: [],
    loading: false,
    error: null,
    useWixBackend: false,
    addToCart: vi.fn(),
    removeFromCart: vi.fn(),
    updateQuantity: vi.fn(),
    totals: { subtotal: 0, discount: 0, shipping: 0, tax: 0, total: 0 },
  }),
}))
vi.mock('./services/wixCheckoutService', () => ({ initiateCheckout: vi.fn() }))

const CREDIT = 'Built by the Dark Factory - by the Developer Agent'
const COPYRIGHT = `© ${new Date().getFullYear()} ${SITE_NAME}. All rights reserved.`

function renderHomePage() {
  return render(
    <HelmetProvider>
      <MemoryRouter initialEntries={['/']}>
        <App initialProducts={[]} />
      </MemoryRouter>
    </HelmetProvider>
  )
}

const getFooter = () => document.querySelector('footer.app-footer')

describe('App home page footer', () => {
  it('renders the Dark Factory credit after the copyright line in the footer', () => {
    renderHomePage()
    expect(screen.getByText(CREDIT)).toBeDefined()
    const text = getFooter().textContent
    expect(text).toContain(COPYRIGHT)
    expect(text.indexOf(CREDIT)).toBeGreaterThan(text.indexOf(COPYRIGHT) + COPYRIGHT.length)
  })

  it('renders the Dark Factory credit in italics', () => {
    renderHomePage()
    expect(screen.getByText(CREDIT).tagName).toBe('EM')
  })

  it('leaves the existing copyright sentence and the rest of the footer unchanged', () => {
    renderHomePage()
    expect(screen.getByText(COPYRIGHT)).toBeDefined()
    expect(getFooter().textContent.replace(/\s+/g, ' ').trim()).toBe(`${COPYRIGHT} ${CREDIT}`)
  })
})
```
2. Run the new test to verify it fails:

`npx vitest run src/App.test.jsx`

Expected: 3 failing tests. The first two fail with `Unable to find an element with the text: Built by the Dark Factory - by the Developer Agent`; the third fails because the footer text is currently `© <year> Antiques Marketplace. All rights reserved.` and does not equal `${COPYRIGHT} ${CREDIT}`.
3. Implement the change in `src/App.jsx` — replace the whole `<footer className="app-footer">` block (it is the last child of the top-level `<div className="app">`, just after the `{cartDrawerOpen && (<div className="cart-backdrop" …/>)}` block) with:

```jsx
<footer className="app-footer">
  <p>
    &copy; {new Date().getFullYear()} {SITE_NAME}. All rights reserved.{' '}
    <em>Built by the Dark Factory - by the Developer Agent</em>
  </p>
</footer>
```

Do not touch anything else in the file, do not add a CSS rule, and do not hardcode the year. The `{' '}` expression is what guarantees a space between the copyright sentence and the credit while leaving the copyright sentence in its own text node.
4. Run the new test to verify it passes:

`npx vitest run src/App.test.jsx`

Expected: `Test Files 1 passed (1)`, `Tests 3 passed (3)`.
5. Run the whole unit suite to verify no regressions from the shell change:

`npx vitest run`

Expected: the previously existing suites (Cart, CategoryFilter, ImageModal, Pagination, ProductCard, ProductList, ProductModal, ProductPage, SortControls, StockIndicator, …) still pass, with only the 3 new tests added.
6. Commit:

```bash
git add src/App.jsx src/App.test.jsx
git commit -m "feat: add Dark Factory credit to home page footer"
```

**Verification:** `npx vitest run src/App.test.jsx` reports 3 passing tests: (1) the credit text is found inside `footer.app-footer` and its index in the footer's textContent is greater than the end of the `© <year> Antiques Marketplace. All rights reserved.` sentence; (2) `screen.getByText('Built by the Dark Factory - by the Developer Agent').tagName === 'EM'` (browser default italic); (3) the footer's normalised textContent equals exactly `© <year> Antiques Marketplace. All rights reserved. Built by the Dark Factory - by the Developer Agent`, and `screen.getByText` still resolves the bare copyright sentence. `npx vitest run` shows the full pre-existing suite still green.

### 2. Regression gate: prove nothing outside the footer changed

**Objective:** Confirm the one-block edit to the shell leaves lint, typecheck-free build output and the rest of the page (header, nav, cart drawer, product section) intact, so the story's 'No other changes' clause is objectively verified.

**Steps:**

3. Render the shell once more and confirm the non-footer regions are untouched:

4. If the gate is clean, make no commit (there is nothing new to stage); if a fix was required, commit it as `fix: keep footer change isolated`.

**Verification:** `npx eslint src/App.jsx src/App.test.jsx` exits 0 with no output; `npm run build` exits 0; the full `npx vitest run` suite is green so no other component's behaviour was disturbed by the shell edit.
