# Plan: Test Issue for DF issue 803

Story: #282
Issue: [#282](https://github.com/ricardoblackskye/webfeedpoc/issues/282)

Scope: this story reads as shell-scoped work, so a target in the application shell is intended rather than accidental.

## Goal

Add a single italic credit line — 'This is Built by the Dark Factory - by the Developer Agent' — to the existing site footer rendered by the application shell (src/App.jsx), immediately after the copyright sentence, with no other markup, style, routing or data changes. The co-located React Testing Library spec (src/App.test.jsx, which already exists in the repository) is extended in place to pin the exact copy, the italic element and the unchanged copyright line.

## Approach

The only copyright text in this application is rendered by the shell component src/App.jsx (repository evidence: role="shell", mounted for route "/" by both src/main.jsx and src/entry-server.jsx and rendering `<Outlet />` so it is present on every child route). Its footer block is:

  `<footer className="app-footer">`
    `<p>&copy; {new Date().getFullYear()} {SITE_NAME}. All rights reserved.</p>`
  `</footer>`

Because the story says 'Put this next to the copyright text at the bottom of the page', the anchor it names is that exact `<p>. The implementation is therefore one inline addition inside that paragraph: an <em> element whose text content is verbatim 'This is Built by the Dark Factory - by the Developer Agent', separated from the copyright sentence by a literal space so the two do not run together ('© 2026 Antiques Marketplace. All rights reserved. This is Built by the Dark Factory - by the Developer Agent'). <em>` is italic by default in the UA stylesheet and this project ships no rule that resets em to font-style: normal, so no CSS file is touched — that keeps the diff to one production file, honouring 'No other changes'. The alternative reading — a second footer inside src/pages/HomePage.jsx — is rejected: it would duplicate a footer region, would render the credit above the site footer rather than next to the copyright line, and would add a second place to keep in sync. The recorded trade-off is that the credit is not route-conditional: it appears in the shared footer on every route, exactly as the copyright line already does. No route-conditional logic (useLocation matching '/') is added, because that is behaviour the story did not ask for and 'No other changes' forbids scope creep.

Verification strategy: the repository's convention is co-located Vitest + React Testing Library specs (e.g. src/components/Cart.test.jsx alongside src/components/Cart.jsx). src/App.test.jsx already exists in this repository (the previous ExecutionPlan's 'create' action was rejected for exactly that reason), so the plan MODIFIES it: the existing file is opened, its current imports/mocks/tests are preserved verbatim, and the four new footer cases are appended to the existing describe block (adding the hook mocks/provider wrapper only where the file does not already supply them). App.jsx reads products through useWixProducts (src/hooks/useWixProducts) and cart state through useWixCart (src/hooks/useWixCart); the spec mocks both modules so no network or Wix client is involved, then renders App inside MemoryRouter + HelmetProvider + QueryClientProvider, which is the same provider stack src/main.jsx uses. Assertions are made on the rendered DOM only: the exact string, its EM tag name, its position inside footer.app-footer and inside the same `<p>` as the copyright text, plus a regression assertion that the copyright sentence is unchanged.

Review focus (inputs/conditions the story implies but does not spell out, each pinned by a test in Task 1):
1. Exact copy — a hyphen-minus with single spaces around it, not an en/em dash, and the capitalisation 'Dark Factory'/'Developer Agent'; any typographic substitution fails the acceptance test.
2. JSX whitespace collapsing — the credit must be preceded by a literal space ({" "} or a leading space in the string) so it does not concatenate onto 'reserved.'; asserted by reading the parent `<p>` textContent.
3. Italic rendering — assert the element is EM rather than relying on a class, so no stylesheet regression can silently un-italicise it.
4. SSR/prerender path — App.jsx is rendered to static HTML by src/entry-server.jsx via scripts/prerender.mjs; the credit must be plain markup with no client-only API, so it appears in the prerendered home page HTML.
5. Year rollover — the copyright uses new Date().getFullYear(); the credit must sit outside any date-conditional expression so it never disappears on 1 January.
6. No regression in the existing spec — every test already present in src/App.test.jsx must still pass after the modification.

## Tasks

### 1. Render the Dark Factory credit line in the site footer and extend the existing App spec

**Objective:** Add an italic `<em>` with the exact story copy inside the existing footer paragraph of src/App.jsx, next to the copyright sentence, and prove it by extending the already-existing co-located RTL spec src/App.test.jsx (new cases appended, existing cases preserved) which also proves the copyright line is untouched.

**Files:** `src/App.jsx`, `src/App.test.jsx`

**Steps:**

1. Open the existing src/App.test.jsx and read it end to end BEFORE editing. Record which imports, mocks, render helpers and test cases it already contains; every one of them must survive this change untouched. Do NOT overwrite or regenerate the file.
2. 3. Ensure src/App.test.jsx can mount App with the same provider stack src/main.jsx uses — render(`<MemoryRouter><HelmetProvider><QueryClientProvider client={new QueryClient({ defaultOptions: { queries: { retry: false } } })}><App /></QueryClientProvider></HelmetProvider></MemoryRouter>`) — reusing an existing render helper if the file already defines one, and define const CREDIT = 'This is Built by the Dark Factory - by the Developer Agent'.
4. Append the failing test 'renders the Dark Factory credit line in the site footer with the exact story copy': const credit = screen.getByText(CREDIT); expect(credit).toBeInTheDocument(); expect(credit.textContent).toBe(CREDIT).
5. Append the failing test 'renders the credit line as an em element so it displays in italics': expect(screen.getByText(CREDIT).tagName).toBe('EM').
6. Append the failing test 'renders the credit line alongside the copyright text inside the footer paragraph': const credit = screen.getByText(CREDIT); expect(credit.closest('footer.app-footer')).not.toBeNull(); expect(credit.parentElement.textContent).toMatch(/© \d{4} Antiques Marketplace\. All rights reserved\./); expect(credit.parentElement.textContent).toContain(CREDIT); expect(credit.parentElement.textContent).toContain('reserved. ' + CREDIT).
7. Append the regression test 'keeps the existing copyright text and footer structure intact': expect(screen.getByText(/© \d{4} Antiques Marketplace\. All rights reserved\./)).toBeInTheDocument(); expect(document.querySelectorAll('footer.app-footer')).toHaveLength(1).
8. Run npx vitest run src/App.test.jsx — expect the four new cases to FAIL with 'Unable to find an element with the text: This is Built by the Dark Factory - by the Developer Agent' while the pre-existing cases in the file still pass.
9. In src/App.jsx, extend the existing footer paragraph (no other line in the file changes) to: `<p>&copy; {new Date().getFullYear()} {SITE_NAME}. All rights reserved.{' '}<em>This is Built by the Dark Factory - by the Developer Agent</em></p>`. Copy the string byte-for-byte from the story: one hyphen-minus, single spaces either side, no trailing period.
10. Run npx vitest run src/App.test.jsx — expect PASS for the four new cases plus every pre-existing case in the file.
11. Run the full unit suite and the linter: npm test and npm run lint — expect zero failures and zero new lint errors (no new production imports, no unused variables, PropTypes untouched).
12. Commit: git add src/App.jsx src/App.test.jsx && git commit -m "feat: add Dark Factory credit line to site footer".

**Verification:** npx vitest run src/App.test.jsx passes every case in the file — the four new footer cases (exact copy present, element is EM, credit sits inside footer.app-footer in the same `<p>` as the copyright sentence with a single space separator, copyright text unchanged) plus all pre-existing cases that were in the file before this change; npm test passes the whole suite; npm run lint reports no new errors. Optionally confirm the static/prerendered home page contains the string by running npm run build:prerender and grepping dist/index.html for 'This is Built by the Dark Factory - by the Developer Agent'.
