# Plan: Test Issue for DF issue #698

Story: #237
Issue: [#237](https://github.com/ricardoblackskye/webfeedpoc/issues/237)

## Goal

Add one italic footer line reading "Built by the Dark Factory - by the Developer Agent" to the home page only. The change lives entirely in the home page component (the route "/" page), uses a semantic `<em>` element for italics so no stylesheet is touched, and is proven by a co-located Vitest/Testing-Library test. No other file, style, route, or behaviour changes.

## Approach

The home page is the index route of the App shell: src/entry-server.jsx declares `<Route path="/" element={<App .../>}><Route index element={<HomePage />} />` and src/main.jsx mirrors that table for the client, so `src/pages/HomePage.jsx` is the only place where a line can appear on the home page and nowhere else. App.jsx already owns a site-wide `<footer className="app-footer">` that renders on every route (including /products/:slug, /category/:categoryName and /architecture); because the story asks for the home page and says "No other changes", App.jsx is deliberately NOT touched — putting the line there would leak it onto every route.

The implementation is a single JSX block appended as the last child of HomePage's returned fragment, after the `{selectedProduct && <ProductModal ... />}` block: `<footer className="home-footer"><p><em>Built by the Dark Factory - by the Developer Agent</em></p></footer>`. Italics come from `<em>`'s default user-agent styling, so no CSS file is created or modified — that keeps the diff to the home page plus its test, which is what "no other changes" demands. The class name is added only so the block can be selected later; it has no stylesheet behind it.

Test strategy: HomePage consumes six keys from `useOutletContext()` (products, loading, error, categories, productCounts, addToCart) and `useSearchParams` from react-router-dom v7, so the test cannot render it bare. The co-located test file `src/pages/HomePage.test.jsx` (same convention as `src/components/Cart.test.jsx`, which renders its component with @testing-library/react and asserts via `screen.getByText`) wraps HomePage in `<MemoryRouter initialEntries={['/']}>` with a parent route whose element is `<Outlet context={ctx} />`, supplying a fully-populated context object with an empty product list. This exercises the real router and the real context contract rather than mocking react-router-dom. Using `products: []` also pins the empty-state path, proving the footer renders regardless of product data.

Global constraints: the copy is exactly `Built by the Dark Factory - by the Developer Agent` — ASCII space, ASCII hyphen-minus (U+002D, not an en/em dash), ASCII space, no trailing punctuation, no curly quotes. The line must be italic. The line must appear on the home page only. No new npm dependency, no CSS change, no other source file may appear in the diff.

Review focus (inputs/conditions the story implies but a loose test would miss): (1) exact copy — a normalised or regex matcher would let a wrong dash or dropped space through, so the test asserts the literal string via `getByText` with no regex; (2) italics surviving CSS — a global `em { font-style: normal }` reset in index.css (not shown in the evidence) would render the line upright, so the test asserts `tagName === 'EM'` and the reviewer confirms computed `font-style` in the dev server; (3) scope — the line must not leak onto other routes, enforced by Asserting App.jsx is not in the diff; (4) empty/loading/error product states — the footer sits outside every conditional block, pinned by the empty-state test; (5) layout/stacking — a `<footer>` inside `main > section.products-section` must not disturb the existing flex layout or the cart drawer's z-index stacking, checked visually since no CSS is added.

## Tasks

### 1. Render the italic Dark Factory footer line on the home page

**Objective:** HomePage renders a footer whose line is exactly "Built by the Dark Factory - by the Developer Agent" inside an `<em>` element, proven by a test that fails first and passes after the change.

**Files:** `src/pages/HomePage.jsx`, `src/pages/HomePage.test.jsx`

**Steps:**

1. Create (or, if it already exists, append to) src/pages/HomePage.test.jsx with imports { describe, it, expect, vi } from 'vitest', { render, screen } from '@testing-library/react', { MemoryRouter, Routes, Route, Outlet } from 'react-router-dom' and the component from './HomePage'.
2. Add the shared render helper: function renderHomePage(context = {}) { const ctx = { products: [], loading: false, error: null, categories: [], productCounts: { All: 0 }, addToCart: vi.fn(), ...context }; return render(`<MemoryRouter initialEntries={['/']}><Routes>`<Route path="/" element={`<Outlet context={ctx} />`}><Route index element={`<HomePage />`} />`</Route></Routes></MemoryRouter>`) } — the Outlet wrapper is required because HomePage calls useOutletContext() for those six keys and useSearchParams needs a Router.
3. Write the failing tests: it('renders the Dark Factory footer line with the exact text on the home page', () => { renderHomePage(); expect(screen.getByText('Built by the Dark Factory - by the Developer Agent')).toBeDefined() }) and it('renders the Dark Factory footer line inside an em element so it displays in italics', () => { renderHomePage(); const line = screen.getByText('Built by the Dark Factory - by the Developer Agent'); expect(line.tagName).toBe('EM'); expect(line.closest('footer')).not.toBeNull() }).
4. Run: npx vitest run src/pages/HomePage.test.jsx — expected FAIL with 'Unable to find an element with the text: Built by the Dark Factory - by the Developer Agent'.
5. In src/pages/HomePage.jsx, add as the final child of the returned fragment (immediately after the `{selectedProduct && (<ProductModal ... />)}` block and before the closing </>): `<footer className="home-footer"><p><em>Built by the Dark Factory - by the Developer Agent</em></p></footer>. Do not add or import a CSS file — <em>` is italic by default, and touching styles would break the 'no other changes' requirement.
6. Run: npx vitest run src/pages/HomePage.test.jsx — expected PASS, 2 tests.
7. Commit: git add src/pages/HomePage.jsx src/pages/HomePage.test.jsx && git commit -m "feat(home): add Dark Factory footer line to home page".

**Verification:** `npx vitest run src/pages/HomePage.test.jsx` reports 2 passing tests; in both, screen.getByText resolves the literal string 'Built by the Dark Factory - by the Developer Agent' (no regex), and in the second the resolved node's tagName is 'EM' and it has a `<footer>` ancestor.

### 2. Regression guard: no other home page or repository change

**Objective:** Prove the added line left the rest of the home page and the rest of the repository behaviourally untouched, and that the diff is confined to the home page and its test.

**Files:** `src/pages/HomePage.test.jsx`

**Steps:**

1. Append a regression test to src/pages/HomePage.test.jsx: it('still renders existing home page content unchanged after adding the footer line', () => { renderHomePage(); expect(screen.getByText('No products available')).toBeDefined(); expect(screen.getByText('Built by the Dark Factory - by the Developer Agent')).toBeDefined() }) — the empty-product-list state comes from HomePage's existing `!loading && products.length === 0` branch.
2. Run: npx vitest run src/pages/HomePage.test.jsx — expected PASS, 3 tests.
3. Run the whole unit suite: npm test -- --run — expected PASS with no previously green suite failing (proves the Cart, CategoryFilter, ImageModal, Pagination, ProductCard, ProductList, ProductModal, ProductPage, SortControls and StockIndicator suites are unaffected).
4. Run: npm run lint — expected no new errors (the added JSX is plain and introduces no unused imports).
5. Run: git diff --name-only HEAD~2 — expected output lists only src/pages/HomePage.jsx and src/pages/HomePage.test.jsx; src/App.jsx must NOT appear, because its site-wide `<footer className="app-footer">` would show the line on every route.
6. Commit: git add src/pages/HomePage.test.jsx && git commit -m "test(home): pin existing home page behaviour after footer addition".

**Verification:** `npm test -- --run` is fully green (including the 3 tests in src/pages/HomePage.test.jsx), `npm run lint` reports no new errors, and `git diff --name-only HEAD~2` shows exactly src/pages/HomePage.jsx and src/pages/HomePage.test.jsx — no App.jsx, no CSS, and no other file.
