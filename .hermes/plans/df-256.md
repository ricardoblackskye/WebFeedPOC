# Plan: Test issue for DF issue #739

Story: #256
Issue: [#256](https://github.com/ricardoblackskye/webfeedpoc/issues/256)

## Goal

Adds exactly one italic footer line ('Built by the Dark Factory - by the Developer Agent') to the existing home page component only. No global layout, styling, dependency, or routing changes, and no new files are introduced.

## Approach

The `/` route renders `src/pages/HomePage.jsx` (evidence: `src/entry-server.jsx` maps the index route to `<HomePage />`, and `src/main.jsx` does the same). Adding the line there scopes it to the home page and leaves `src/App.jsx`'s global footer and every other route untouched. The markup is a single `<footer><p><em>Built by the Dark Factory - by the Developer Agent</em></p></footer>` appended as the last child of the fragment returned by `HomePage`, after the `{selectedProduct && (...)}` block. Because no dedicated HomePage test file exists in this repository, the regression test for the new line is added to the existing Vitest suite `src/components/ProductList.test.jsx` (the suite that already renders the home page's product surface). That suite renders the real `HomePage` with `react-router-dom` partially mocked — `importOriginal()` is spread so `Link`/other exports stay real, while `useOutletContext` returns an empty product context and `useSearchParams` returns an empty search-param pair — so `HomePage` renders without a Router/Outlet. With an empty product list the `Helmet` block is not rendered, so no `HelmetProvider` is needed. Bare `<em>` (no inline style, no CSS class) satisfies 'in italics' without touching any stylesheet.

## Tasks

### 1. Add the Dark Factory footer line to the home page and cover it with the existing Vitest suite

**Objective:** Render the exact italic footer line on the home page only and prove it (plus no regressions) with a focused test added to an existing test file.

**Files:** `src/pages/HomePage.jsx`, `src/components/ProductList.test.jsx`

**Steps:**

1. In `src/components/ProductList.test.jsx`, add a partial mock at module scope so the real `HomePage` can be rendered without a Router: `vi.mock('react-router-dom', async (importOriginal) => { const actual = await importOriginal(); return { ...actual, useOutletContext: () => ({ products: [], loading: false, error: null, categories: [], productCounts: { All: 0 }, addToCart: () => {} }), useSearchParams: () => [new URLSearchParams(), () => {}] } })`. Spreading `actual` keeps `Link` and other exports real, so the file's existing ProductList tests keep working.
2. In the same file, import `HomePage` from `../pages/HomePage` and add a `describe('HomePage Dark Factory footer', ...)` block.
3. Add test `renders the Dark Factory footer line in italics`: render `<HomePage />` and assert `screen.getByText('Built by the Dark Factory - by the Developer Agent').tagName` is `'EM'`, and that its closest `footer` element is not null.
4. Add test `keeps existing home page content rendered alongside the new footer`: render `<HomePage />` and assert `screen.getByRole('heading', { name: /All Items/ })` is defined (the pre-existing page heading), proving no other home page content changed.
5. Run `npx vitest run src/components/ProductList.test.jsx` and confirm the new footer test FAILS with 'Unable to find an element with the text: Built by the Dark Factory - by the Developer Agent'.
6. In `src/pages/HomePage.jsx`, inside the returned fragment, immediately after the `{selectedProduct && ( <ProductModal ... /> )}` block and before the closing `</>`, add: `<footer><p><em>Built by the Dark Factory - by the Developer Agent</em></p></footer>`. Do not add a `className`, inline `style`, import, or CSS rule — the `<em>` element alone provides the italics.
7. Run `npx vitest run src/components/ProductList.test.jsx` again and confirm the two new tests and all pre-existing ProductList tests pass.
8. Run `npm run lint` and `npm run typecheck` and confirm both pass with no new warnings/errors.
9. Run `npm run build` to confirm the page still builds and prerenders.
10. Commit with `git add src/pages/HomePage.jsx src/components/ProductList.test.jsx && git commit -m "feat: add Dark Factory footer line to home page"`.

**Verification:** `npx vitest run src/components/ProductList.test.jsx` passes (new footer test + existing ProductList tests); `npm run lint` passes; `npm run typecheck` passes; `npm run build` succeeds. Manual check: the `/` route shows 'Built by the Dark Factory - by the Developer Agent' in italics below the product grid, and `/products/:slug`, `/category/:categoryName`, `/architecture`, `/about` and `/orders` are visually unchanged.
