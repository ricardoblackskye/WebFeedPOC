# Plan: Consistent Yellow Text

Story: #242
Issue: [#242](https://github.com/ricardoblackskye/webfeedpoc/issues/242)

## Goal

Make every navigation-related label on the home page use one identical bold gold treatment (the same colour already used by the category-button hover state, var(--color-gold) = #D4AF37, with font-weight 700). Scope: the 'Categories' block (heading + category buttons + their counts), the 'All Items (106)' heading rendered directly beneath it, the 'Search Products' placeholder inside the search box, and the 'Sort by' label plus the 'Name (A-Z)' select value and its arrow. No behaviour, markup structure, or data flow changes are required: all of the affected text is styled by two existing stylesheets (CategoryFilter.css, SortControls.css), so the fix is a pure token/selector change there, proven by file-content + DOM assertions added to the two existing component test files.

## Risks

- The 'All Items (106)' heading lives in src/pages/HomePage.jsx, which is outside the permitted change set, so its colour cannot be set at the element. (Mitigation: Anchor the rule on the .product-count marker span HomePage already renders via `:has()`, which can only match that one heading; the count span also gets font-weight: 700 directly.)
- :has() is unsupported by very old browsers, which would drop that single rule. (Mitigation: The Playwright project list targets current Chromium only; the rest of the change (CategoryFilter/SortControls) is plain CSS with no feature dependency. No functional behaviour depends on the rule.)
- Exact selector names inside SortControls.css / SortControls.jsx were not visible in the evidence, so a selector could be misnamed. (Mitigation: The step deliberately edits the existing rules in place rather than inventing new class names, and each test pairs a stylesheet assertion with a DOM assertion (placeholder / label / combobox), so a mismatch fails loudly instead of silently passing.)
- CSS-file-content tests can be seen as layout-brittle. (Mitigation: Assertions normalise whitespace, collect declarations per selector regardless of order, and accept either the design token or its literal hex value.)
- Native select chevrons cannot be recoloured in every browser. (Mitigation: If SortControls uses the native arrow and it cannot be styled, leave it and document the limitation in the PR description rather than forcing appearance: none (which would be a behaviour change beyond the story).)
