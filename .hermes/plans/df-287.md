# Plan: Test issue for the dark Factory

Story: #287
Issue: [#287](https://github.com/ricardoblackskye/webfeedpoc/issues/287)

Scope: this story reads as shell-scoped work, so a target in the application shell is intended rather than accidental.

## Goal

Add the single footer credit line 'This is Built by the Dark Factory - by the Developer Agent' (in italics) to the existing copyright paragraph rendered by the app shell, src/App.jsx, and extend its existing co-located spec, src/App.test.jsx, to prove the copy, the italics, the inline placement next to the copyright text, and that nothing else in the footer or on a non-home route changes. No stylesheet, route, data-layer, or dependency changes are needed: italics come from a semantic `<em>` element.

## Approach

Goal: render the exact line 'This is Built by the Dark Factory - by the Developer Agent' in italics immediately after the existing copyright sentence at the bottom of the home page, and change nothing else.

Architecture / where the edit belongs: the story says the line goes 'next to the copyright text at the bottom of the page'. In REPOSITORY EVIDENCE the only copyright text in the repository is the `<footer className="app-footer"> block inside src/App.jsx (role: shell, 'renders an outlet, so it is rendered on every route'). App is the route element for '/' in both src/main.jsx (BrowserRouter) and src/entry-server.jsx (StaticRouter, used by scripts/prerender.mjs), and src/pages/HomePage.jsx renders inside it through <Outlet>. So the home page's footer is owned by src/App.jsx; that is the only rendered file that needs to change. The credit is appended INSIDE the existing <p>` (after 'All rights reserved.') so it literally sits next to the copyright text rather than in a second block, and the two are separated by an explicit JSX space expression {' '} so the sentence does not run together in textContent or in a screen reader.

Co-located spec: src/App.test.jsx ALREADY EXISTS in this repository (a TARGET CONTRACT validation error confirmed it), so it is touched as MODIFY, never create. The spec is opened and read first; the new footer cases are appended to the existing describe alongside whatever cases are already there, and no existing case, import, or mock is deleted or weakened. If the existing spec already mocks ./hooks/useWixProducts, ./hooks/useWixCart or the Cart component, those mocks are reused as-is rather than re-declared (duplicate vi.mock registrations for the same module would shadow the originals). Only if a needed mock is genuinely absent is it added, following the existing file's own style.

Italics: the credit is wrapped in a semantic `<em>` element, which the user-agent stylesheet renders as font-style: italic. This satisfies 'in italics' without touching a stylesheet, keeps the diff to a single rendered file, and is directly assertable in jsdom (jsdom does not apply stylesheets, so a CSS-only implementation would be untestable in the co-located spec — the same limitation called out in src/components/CategoryFilter.test.jsx).

Tech stack: React 18 with the automatic JSX runtime (tsconfig 'jsx': 'react-jsx', so `<em> needs no import), react-router-dom v7 (MemoryRouter in tests, StaticRouter from 'react-router' for the SSR check — the exact import used by src/entry-server.jsx), react-helmet-async (App renders <Helmet>`, so tests wrap it in HelmetProvider), Vitest + @testing-library/react (jsdom). No new npm packages.

TDD shape: add the failing footer cases to src/App.test.jsx first and watch them fail, then make the one-line JSX change in src/App.jsx and re-run. App pulls its data through two hooks (./hooks/useWixProducts, ./hooks/useWixCart) and renders ./components/Cart, so the spec renders App inside HelmetProvider + MemoryRouter with those hooks mocked to empty data; a further case renders App through react-dom/server's renderToString with StaticRouter to prove the credit survives the prerender path in scripts/prerender.mjs. Verification commands: `npx vitest run src/App.test.jsx`, then `npx vitest run` (no regressions), then `npm run lint`.

Global constraints (verbatim from the story): exact copy 'This is Built by the Dark Factory - by the Developer Agent'; rendered in italics; placed next to the copyright text at the bottom of the page; no other changes.

Review Focus (input classes / failure modes this one-line change can still get wrong, most likely first):
1. Missing separator space — the footer would read '…All rights reserved.This is Built by…'. Expected: exactly one space before the credit; pinned by the /All rights reserved\.\s+This is Built by the Dark Factory - by the Developer Agent$/ assertion in test 3.
2. Year rollover — a spec that hardcodes new Date().getFullYear() fails on 1 January. Expected: the copyright assertion is year-agnostic (only 'All rights reserved.' is matched); stated in test 3.
3. Global footer on non-home routes — the shell renders on every route, so the credit also appears on /products/:slug, /category/:categoryName and /architecture. Expected: it renders exactly once per page and does not break those routes; pinned by test 5.
4. Server-rendered/prerendered markup — scripts/prerender.mjs writes static HTML for every route through renderToString; the credit must be present in that string and must not depend on browser-only APIs. Expected: present and static; pinned by test 4.
5. Empty catalogue — HomePage renders when Wix returns no products; the footer must still render. Expected: footer present with the credit; pinned because every test renders App with products: [] (test 1).
6. Clobbering the existing spec — src/App.test.jsx already exists, so edits must be additive: existing cases keep passing unchanged and no duplicate vi.mock for an already-mocked module is introduced; caught by `npx vitest run` (full suite) being green, not just the new cases.

## Tasks

### 1. Add the Dark Factory credit to the app footer and extend its co-located spec

**Objective:** Add the failing footer cases to the existing spec src/App.test.jsx, then append an italic `<em>` credit line next to the existing copyright sentence in src/App.jsx until the spec passes, leaving every other file untouched.

**Files:** `src/App.jsx`, `src/App.test.jsx`

**Steps:**

1. Step 1: Read the existing src/App.test.jsx end to end (it already exists — do NOT create or overwrite it). Note its current imports, its existing describe/it cases, and which modules it already mocks (especially ./hooks/useWixProducts, ./hooks/useWixCart and ../components/Cart). All later edits are additive: no existing case, import, or mock may be removed, reordered, or weakened.
2. Step 2: In src/App.test.jsx, add only the imports that are genuinely missing from a case that needs them: `import { renderToString } from 'react-dom/server'`, `import { MemoryRouter } from 'react-router-dom'`, `import { StaticRouter } from 'react-router'`, `import { HelmetProvider } from 'react-helmet-async'`, `import { screen } from '@testing-library/react'`. Reuse the existing `import App from './App'` (the default export of src/App.jsx) if the file already has it instead of adding a duplicate.
3. Step 3: In src/App.test.jsx, ensure the two data hooks App consumes are mocked. If they are already mocked, reuse those mocks verbatim. If they are not, add `vi.mock('./hooks/useWixProducts', () => ({ useWixProducts: () => ({ products: [], loading: false, error: null, refreshing: false }) }))` and `vi.mock('./hooks/useWixCart', () => ({ useWixCart: () => ({ cart: [], loading: false, error: null, useWixBackend: false, addToCart: vi.fn(), removeFromCart: vi.fn(), updateQuantity: vi.fn(), totals: { subtotal: 0, discount: 0, shipping: 0, tax: 0, total: 0 } }) }))` exactly once each — never a second registration for a module the file already mocks. Then add `const CREDIT = 'This is Built by the Dark Factory - by the Developer Agent'` and the helper `const renderApp = (path = '/') => render(<HelmetProvider><MemoryRouter initialEntries={[path]}><App /></MemoryRouter></HelmetProvider>)`.
4. Step 4: Append the failing test `renders the Dark Factory credit in the footer`: `const { container } = renderApp()`; `const footer = container.querySelector('footer.app-footer')`; `expect(footer).not.toBeNull()`; `expect(footer.textContent).toContain(CREDIT)`. (This also pins the empty-catalogue case, because the mocked catalogue is empty.)
5. Step 5: Append the failing test `renders the credit in italics via an <em> element`: `const credit = container.querySelector('footer.app-footer em')`; `expect(credit).not.toBeNull()`; `expect(credit.textContent).toBe(CREDIT)` — `<em>` is the element whose UA styling is font-style: italic, so the assertion is the italics requirement in jsdom, which does not apply stylesheets.
6. Step 6: Append the failing test `places the credit next to the copyright text and adds no other footer content`: `const footer = container.querySelector('footer.app-footer')`; `expect(footer.querySelectorAll('p')).toHaveLength(1)`; `const line = footer.querySelector('p')`; `expect(line.textContent).toMatch(/All rights reserved\.\s+This is Built by the Dark Factory - by the Developer Agent$/)`. The regex pins the separating space (Review Focus 1) and deliberately never asserts the literal year, so the test passes on 1 January (Review Focus 2).
7. Step 7: Append the failing test `renders the credit in server-rendered HTML`: `const html = renderToString(<HelmetProvider><StaticRouter location="/"><App /></StaticRouter></HelmetProvider>)`; `expect(html).toContain(CREDIT)` — this mirrors the prerender path (scripts/prerender.mjs calls `render()` in src/entry-server.jsx, which uses exactly this StaticRouter import) and proves the credit is static markup, not client-only (Review Focus 4).
8. Step 8: Append the failing test `renders the credit exactly once on a non-home route`: `renderApp('/products/vase')`; `expect(screen.getAllByText(CREDIT)).toHaveLength(1)` — the footer is global chrome, so a non-home route must still render it, exactly once (Review Focus 3).
9. Step 9: Run `npx vitest run src/App.test.jsx`. Expected: FAIL — the new credit cases report 'Unable to find an element with the text: This is Built by the Dark Factory - by the Developer Agent' and `querySelector('footer.app-footer em')` returns null; the pre-existing cases in the file must still pass untouched. No test may be adjusted to make the suite green.
10. Step 10: Modify src/App.jsx — in the App component's returned JSX (the block immediately before the closing `</div>` of the `app` container) replace the footer paragraph with `<footer className="app-footer">` / `  <p>` / `    &copy; {new Date().getFullYear()} {SITE_NAME}. All rights reserved.{' '}` / `    <em>This is Built by the Dark Factory - by the Developer Agent</em>` / `  </p>` / `</footer>`. Keep the `new Date().getFullYear()` expression and `SITE_NAME` exactly as they are; add no imports (the automatic JSX runtime resolves `em`), no CSS classes, no props, and change no other markup, route, or hook usage in the file.
11. Step 11: Run `npx vitest run src/App.test.jsx`. Expected: PASS — every case in the file green, including the pre-existing ones and the new footer cases.
12. Step 12: Run `npx vitest run` for the whole suite and `npm run lint`. Expected: the existing component suites (Cart, CategoryFilter, ImageModal, ProductList, …) still pass unchanged and ESLint reports no errors, proving 'no other changes' and that the existing App spec was not clobbered (Review Focus 6).
13. Step 13: Commit: `git add src/App.jsx src/App.test.jsx` then `git commit -m "feat: add Dark Factory credit to home page footer"`.

**Verification:** `npx vitest run src/App.test.jsx` passes every case in the file — the pre-existing ones plus the 5 new footer cases: (1) the footer contains the exact copy 'This is Built by the Dark Factory - by the Developer Agent'; (2) the copy lives in an `<em> element (italics); (3) the footer has exactly one <p>` and its textContent matches /All rights reserved\.\s+This is Built by the Dark Factory - by the Developer Agent$/ (next to the copyright, correctly spaced, year-agnostic); (4) renderToString with StaticRouter contains the copy (prerender path); (5) the copy renders exactly once on /products/vase. `npx vitest run` shows no regressions in the existing suites and `npm run lint` exits clean.
