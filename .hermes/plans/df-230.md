# Plan: Test for the Dark Factory

Story: #230
Issue: [#230](https://github.com/ricardoblackskye/webfeedpoc/issues/230)

## Goal

Append one italic credit line — 'Built by the Dark Factory - by the Developer Agent' — to the bottom of the home page by modifying src/pages/HomePage.jsx, the component the route table mounts for '/', and pin it with colocated React Testing Library tests in src/pages/HomePage.test.jsx. No stylesheets, no dependencies, no route changes, and no edits to the shared App shell footer or to the shared ProductList grid, so the credit appears on the home page only.

## Approach

The story is a one-line, home-page-only copy change, so the whole implementation is confined to src/pages/HomePage.jsx — the file the evidence names as the page for route '/': src/entry-server.jsx declares `<Route path="/" element={<App initialProducts={data.products} />}>` with `<Route index element={<HomePage />} />`, and src/main.jsx mirrors the same table in the browser. HomePage composes the home page out of CategoryFilter, SortControls, ProductList, Pagination and ProductModal, and receives products/loading/error/categories/productCounts/addToCart through useOutletContext() supplied by src/App.jsx (the shell that also renders `<Outlet/>` and an app-footer).

The credit line becomes the final page-content node of HomePage's returned fragment: rendered after the ProductList + Pagination block and after the 'No products found' / 'No products available' states, immediately before the `{selectedProduct && (<ProductModal .../>)}` conditional — which renders nothing unless a product is selected, so the credit stays the last element in the DOM and therefore the bottom of the home page. It is written as `<p className="home-credit"><em>Built by the Dark Factory - by the Developer Agent</em></p>`: the semantic `<em>` element supplies italics without adding or editing any CSS (the project keeps a stylesheet beside each component and HomePage has none, so a new .css file would violate 'no other changes'), the class name is a stable test hook, and the copy is a plain hyphen-minus with one space on each side and the exact capitalisation from the story.

Two alternatives were rejected on evidence. src/App.jsx already renders `<footer className="app-footer">`, but App is the shell for every route — it renders the `products-section` Outlet — so editing it would put the line on /products/:slug, /category/:categoryName, /about and every other route. src/components/ProductList.jsx is imported by HomePage but is the shared product grid also used by the category route, so a footer there is not home-page-only; it is also covered by its own colocated test, which 'no other changes' tells us not to disturb.

Tests follow the repo's colocated vitest + @testing-library/react pattern (see src/components/ProductList.test.jsx, src/components/Cart.test.jsx, src/components/CategoryFilter.test.jsx) and render HomePage under a MemoryRouter whose parent Route injects the outlet context with `<Outlet context={...} />`, because HomePage's data comes from useOutletContext() and would be undefined in a bare render. Verification is strict TDD: failing tests first, then the JSX, then the whole suite plus lint and typecheck so a regression anywhere in the shared shell is caught.

Review Focus (inputs/conditions the spec implies but does not spell out, most likely first):
1. Exact copy — an en dash, smart quotes, doubled spaces or changed capitalisation silently breaks the requirement; the test asserts the literal string 'Built by the Dark Factory - by the Developer Agent'.
2. Italics — italics delivered by an external rule that was never added would not render; the test asserts the text node is inside an `<em>`.
3. Empty catalogue / loading / error state — the credit must still sit at the bottom of the page, not only when products exist.
4. Zero search matches ('No products found') — the credit must remain the last element after the empty-state message.
5. Leakage to other routes — because App (the shell) renders on every route, the change must stay in HomePage.jsx; the test asserts the credit renders exactly once on the home page and the full suite confirms the shared components and app footer are untouched.

## Tasks

### 1. Add the Dark Factory credit line to the home page (TDD)

**Objective:** Add the italic credit line 'Built by the Dark Factory - by the Developer Agent' as the last content node of the home page, driven by a failing React Testing Library test.

**Files:** `src/pages/HomePage.test.jsx`, `src/pages/HomePage.jsx`

**Steps:**

1. Write the failing tests in `src/pages/HomePage.test.jsx` (create the file if it does not already exist, following the colocated vitest + @testing-library/react pattern of `src/components/ProductList.test.jsx`). HomePage reads its data from `useOutletContext()`, so the render helper must supply that context through a parent route:

```jsx
import { describe, it, expect, vi } from 'vitest'
import { render, screen } from '@testing-library/react'
import { MemoryRouter, Routes, Route, Outlet } from 'react-router-dom'
import HomePage from './HomePage'

const CREDIT = 'Built by the Dark Factory - by the Developer Agent'

const baseContext = {
  products: [
    { id: '1', name: 'Walnut Writing Desk', price: 480, category: 'Furniture', description: 'Georgian walnut desk' },
    { id: '2', name: 'Brass Oil Lamp', price: 90, category: 'Lighting', description: 'Victorian oil lamp' },
  ],
  loading: false,
  error: null,
  categories: ['Furniture', 'Lighting'],
  productCounts: { All: 2, Furniture: 1, Lighting: 1 },
  addToCart: vi.fn(),
}

function renderHomePage({ context = {}, initialEntry = '/' } = {}) {
  return render(
    <MemoryRouter initialEntries={[initialEntry]}>
      <Routes>
        <Route element={<Outlet context={{ ...baseContext, ...context }} />}>
          <Route path="/" element={<HomePage />} />
        </Route>
      </Routes>
    </MemoryRouter>
  )
}

describe('HomePage Dark Factory credit', () => {
  it('renders the Dark Factory credit line with the exact copy on the home page', () => {
    renderHomePage()
    expect(screen.getByText(CREDIT)).toBeDefined()
  })

  it('renders the Dark Factory credit line in italics', () => {
    renderHomePage()
    expect(screen.getByText(CREDIT).tagName).toBe('EM')
  })

  it('renders the Dark Factory credit line after the product list as the last element on the page', () => {
    const { container } = renderHomePage()
    const credit = container.querySelector('.home-credit')
    expect(credit).not.toBeNull()
    expect(credit.textContent).toBe(CREDIT)
    const heading = screen.getByRole('heading', { level: 2, name: /All Items/ })
    expect(heading.compareDocumentPosition(credit) & Node.DOCUMENT_POSITION_FOLLOWING).toBeTruthy()
    expect(container.lastElementChild).toBe(credit)
  })
})
```
2. Run: `npx vitest run src/pages/HomePage.test.jsx`
Expected: FAIL — 'Unable to find an element with the text: Built by the Dark Factory - by the Developer Agent' and `credit` is null in the placement test.
3. Implement in `src/pages/HomePage.jsx` by inserting, as the last page-content node of the returned fragment — after the `{!loading && products.length === 0 && (<div className="error">No products available</div>)}` block and before the `{selectedProduct && (<ProductModal ... />)}` block:

```jsx
      <p className="home-credit">
        <em>Built by the Dark Factory - by the Developer Agent</em>
      </p>
```

Exact characters: plain hyphen-minus with one space either side, no en/em dash, no curly quotes. Italics come from the semantic `<em>` element — do not add a stylesheet or a `style={{ fontStyle: 'italic' }}`; `home-credit` is only a hook for the test. The ProductModal conditional stays after the credit so the modal markup remains the last branch in the tree.
4. Run: `npx vitest run src/pages/HomePage.test.jsx`
Expected: PASS — all three credit tests green.
5. Run: `npm run lint`
Expected: no errors or warnings for src/pages/HomePage.jsx or src/pages/HomePage.test.jsx.
6. Commit:

```bash
git add src/pages/HomePage.jsx src/pages/HomePage.test.jsx
git commit -m "feat: add Dark Factory credit line to home page"
```

**Verification:** `npx vitest run src/pages/HomePage.test.jsx` passes with the three credit tests (exact copy, italics, last-element placement); `npm run lint` is clean; the change is committed touching only src/pages/HomePage.jsx and src/pages/HomePage.test.jsx.

### 2. Cover degenerate home-page states and prove nothing else changed

**Objective:** Pin the credit line for the empty-catalogue and no-search-match states, assert it renders exactly once, and run the whole suite plus lint/typecheck to prove no other page or shared component changed.

**Files:** `src/pages/HomePage.test.jsx`

**Steps:**

1. Extend `src/pages/HomePage.test.jsx` using the `renderHomePage` helper from Task 1 with these cases:

```jsx
  it('keeps the credit at the bottom when the catalogue is empty', () => {
    const { container } = renderHomePage({
      context: { products: [], categories: [], productCounts: { All: 0 } },
    })
    expect(screen.getByText('No products available')).toBeDefined()
    const credit = container.querySelector('.home-credit')
    expect(credit).not.toBeNull()
    expect(container.lastElementChild).toBe(credit)
  })

  it('keeps the credit at the bottom when no products match the search', () => {
    const { container } = renderHomePage({ initialEntry: '/?search=zzzzq' })
    expect(screen.getByText('No products found')).toBeDefined()
    const credit = container.querySelector('.home-credit')
    expect(credit).not.toBeNull()
    expect(container.lastElementChild).toBe(credit)
  })

  it('renders the credit line exactly once on the home page', () => {
    const { container } = renderHomePage()
    expect(container.querySelectorAll('.home-credit')).toHaveLength(1)
    expect(screen.getAllByText(CREDIT)).toHaveLength(1)
  })
```
2. Run: `npx vitest run src/pages/HomePage.test.jsx`
Expected: PASS — all credit tests green.
3. Run: `npx vitest run`
Expected: PASS — every pre-existing test in src/components/*.test.jsx (Cart, CategoryFilter, ImageModal, Pagination, ProductCard, ProductList, ProductModal, ProductPage, SortControls, StockIndicator) still passes, proving the shared shell, shared product grid and app footer were not modified.
4. Run: `npm run lint` and `npm run typecheck`
Expected: both clean.
5. Commit:

```bash
git add src/pages/HomePage.test.jsx
git commit -m "test: cover Dark Factory credit line in empty and no-match states"
```

**Verification:** `npx vitest run` passes the full suite including the three new degenerate-state/exactly-once tests; `npm run lint` and `npm run typecheck` are clean; git diff shows only src/pages/HomePage.jsx and src/pages/HomePage.test.jsx changed.
