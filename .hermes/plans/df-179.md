# Plan: Test Issue (Developer Agent)

Story: #179
Issue: [#179](https://github.com/ricardoblackskye/webfeedpoc/issues/179)

## Goal

Add a single italic credit line, 'Built by the Dark Factory', to the home page and nothing else. The change is confined to the home page route component (src/pages/HomePage.jsx), which is the index route rendered under the App shell at path '/'. A co-located test file proves the line exists, is italic, and that the rest of the home page output is unchanged. No new dependencies, no shared components, no routing, styling or data changes.

## Approach

The home page is served by the route table in src/entry-server.jsx and src/main.jsx, both of which mount src/pages/HomePage.jsx as the index child of the App shell at path '/'. The story asks for a footer line on the home page only, so the edit belongs in that page component rather than in the App shell footer (src/App.jsx), which renders on every route and would therefore change pages the story explicitly excludes ('No other changes'). HomePage returns a React fragment whose last element is the conditional ProductModal; the credit line is appended as the final sibling of that fragment so it renders at the bottom of the home page content, after the product list, pagination and modal. It is marked up as <footer className="home-footer"><p><em>Built by the Dark Factory</em></p></footer> — the <em> element carries the italics the story requires, and the wrapper class gives a stable hook for the test and any future styling work without introducing a new stylesheet. The component's existing state, effects, memos, props and outlet-context usage are untouched; no new props, no new imports, no CSS file added. Verification is test-first: a new co-located test renders HomePage with the router hooks mocked and asserts both the exact copy and the italic element, plus a regression assertion that the page's existing 'All Items' heading and product count still render, which is the mechanical proof that nothing else on the page changed.

## Tasks

### 1. Add the italic Dark Factory credit line to the home page

**Objective:** Append a single italic footer line reading 'Built by the Dark Factory' to the bottom of the home page output, proven by a co-located test, with no other change to the component.

**Files:** `src/pages/HomePage.jsx`, `src/pages/HomePage.test.jsx`

**Steps:**

1. Write the failing test in src/pages/HomePage.test.jsx. Mock the router hooks used by HomePage: vi.mock('react-router-dom', () => ({ useOutletContext: () => ({ products: [], loading: false, error: null, categories: [], productCounts: { All: 0 }, addToCart: vi.fn() }), useSearchParams: () => [new URLSearchParams(), vi.fn()] })). Import HomePage from './HomePage' and render it inside <HelmetProvider> from 'react-helmet-async'. Case 1: 'renders the Dark Factory credit line on the home page' - const line = screen.getByText('Built by the Dark Factory'); expect(line).toBeDefined(). Case 2: 'renders the credit line inside an <em> element' - expect(line.tagName).toBe('EM') and expect(line.closest('.home-footer')).not.toBeNull(). Case 3 (regression): 'still renders the All Items heading with product count unchanged' - expect(screen.getByRole('heading', { level: 2 }).textContent).toContain('All Items') and expect(screen.getByText('(0)')).toBeDefined().
2. Run: npx vitest run src/pages/HomePage.test.jsx. Expected: FAIL on cases 1 and 2 with 'Unable to find an element with the text: Built by the Dark Factory'; case 3 passes.
3. Implement in src/pages/HomePage.jsx: add, as the final sibling inside the returned fragment, immediately after the '{selectedProduct && (<ProductModal ... />)}' block, exactly this JSX: <footer className="home-footer"><p><em>Built by the Dark Factory</em></p></footer>. Make no other change: do not touch state, effects, useMemo blocks, handlers, prop names, imports, or any existing JSX node.
4. Run: npx vitest run src/pages/HomePage.test.jsx. Expected: PASS, 3 tests passed.
5. Run: npx vitest run. Expected: entire existing suite still green (no other component or page test regressed).
6. Commit: git add src/pages/HomePage.jsx src/pages/HomePage.test.jsx && git commit -m "feat: add Dark Factory credit line to home page"

**Verification:** npx vitest run src/pages/HomePage.test.jsx passes all three cases: the exact string 'Built by the Dark Factory' is present on the rendered home page, it is the text content of an <em> element nested inside the .home-footer wrapper (so it renders italic), and the pre-existing 'All Items (0)' heading still renders unchanged so the page's other output is provably untouched. A full npx vitest run afterwards stays green.
