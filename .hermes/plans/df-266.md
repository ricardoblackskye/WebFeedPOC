# Plan: Test issue for DF - Issue 759 x3

Story: #266
Issue: [#266](https://github.com/ricardoblackskye/webfeedpoc/issues/266)

## Goal

Additive, presentation-only change: the home page ('/' route, rendered by src/pages/HomePage.jsx) gains a single italic credit line reading exactly 'Built by the Dark Factory - by the Developer Agent' at the foot of its content. Because the declared existing-file set for this repository snapshot contains only src/components/* UI files (no pages/, App.jsx or main.jsx is in the Existing files list), the line is anchored to the bottom-most component that HomePage.jsx composes and renders last in its listing — src/components/Pagination.jsx — using its colocated stylesheet (src/components/Pagination.css) and its colocated vitest suite (src/components/Pagination.test.jsx). No data flow, props, routing, cart, product or pagination behaviour changes; the change is one new `<p className="pagination-footer"><em>…</em></p>` element plus one additive CSS rule.

## Approach

Context: The home page is the index route under App (src/main.jsx routes '/' -> App with an index child HomePage; src/entry-server.jsx declares the same table for prerendering). HomePage's evidence shows it imports and renders, in order: CategoryFilter, an `<h2>` item-count heading, SortControls, ProductList, and finally Pagination — so Pagination is the bottom-most element of the home page's content, immediately above the site footer. The target contract restricts every target file to a path that appears verbatim in the declared Existing files list; that list contains only src/components/* for UI (src/pages/HomePage.jsx, src/App.jsx and src/main.jsx appear in evidence but are not declared existing files), so the credit line is implemented in the bottom-most home-page component, src/components/Pagination.jsx, and its colocated stylesheet and test file.

Design: In src/components/Pagination.jsx, render a new paragraph as the last element of the component's returned markup: `<p className="pagination-footer"><em>Built by the Dark Factory - by the Developer Agent</em></p>. The text is copied verbatim from the story (plain hyphen-minus surrounded by spaces — not an en/em dash) and lives in a single module-scope constant so the test and the component cannot drift. <em>` gives semantic emphasis and italic presentation; src/components/Pagination.css adds one additive rule, .pagination-footer { margin-top: 1rem; text-align: center; font-size: 0.875rem; font-style: italic; }, so italic is declared in CSS and not merely inherited from user-agent defaults. If Pagination.jsx early-returns null when there is only one page (totalPages <= 1), the return is restructured to a fragment containing the (unchanged, possibly empty) pagination controls plus the credit line, so the home page never renders without the line. The file must already import './Pagination.css' — the repo's components import their colocated stylesheet (Cart.jsx imports './Cart.css', CategoryFilter.jsx imports './CategoryFilter.css'); if the import is missing it is added, which is part of this same change.

TDD: Tests are written first in src/components/Pagination.test.jsx (vitest + @testing-library/react, the established colocated pattern used by Cart.test.jsx and CategoryFilter.test.jsx; the CSS-contract assertion mirrors CategoryFilter.test.jsx's readFileSync + process.cwd() stylesheet pattern, since jsdom does not apply stylesheets). All 268+ existing component tests are run untouched as the regression gate.

Risk / Review focus: (1) footer must still render on a single-page catalogue where pagination controls are hidden; (2) the exact copy must not be 'improved' into an en dash or a trailing period; (3) the new element must not wrap or displace the existing pagination controls or swallow their click handlers — it is rendered as the last sibling, not inside the control group; (4) accessibility — the line is plain static text, so it must not acquire a role, tabindex, or aria-hidden; (5) 'No other changes' — no other file, route, or prop is touched, and no new npm dependency is added.

### 1. Render the Dark Factory credit line at the foot of the home page

**Objective:** Make the bottom-most component rendered by the home page ('/' -> HomePage.jsx -> Pagination) output the exact text 'Built by the Dark Factory - by the Developer Agent', emphasised with `<em>`, as the last element of its markup, proven by a failing-then-passing test.

4. Add the second failing test 'renders the Dark Factory credit line in italics': render the same props and assert expect(screen.getByText(FOOTER_TEXT).tagName).toBe('EM').
5. Add the third failing test 'places the credit line after the existing pagination markup': const { container } = render(`<Pagination currentPage={1} totalPages={3} onPageChange={vi.fn()} />`); const footer = container.querySelector('.pagination-footer'); expect(footer).not.toBeNull(); expect(footer.parentElement.lastElementChild).toBe(footer).
6. Run: npx vitest run src/components/Pagination.test.jsx — expected FAIL on all three new tests; the pre-existing pagination tests in the file must still pass unchanged.

In src/components/Pagination.jsx, add a module-scope constant const FOOTER_TEXT = 'Built by the Dark Factory - by the Developer Agent' and render, as the LAST child of the component's returned markup, `<p className="pagination-footer"><em>{FOOTER_TEXT}</em></p>`. Use ordinary string interpolation, not dangerouslySetInnerHTML; copy the string verbatim (single hyphen-minus, single spaces, no trailing period).

10. Run: npx vitest run src/components/Pagination.test.jsx — expected PASS: the three new tests plus every pre-existing test in the file (the latter are the untouched regression guard).
11. Commit: git add src/components/Pagination.jsx src/components/Pagination.test.jsx && git commit -m "feat: add Dark Factory credit footer line to home page".
