# Plan: Test issue for DF - Issue 759 x3

Story: #266
Issue: [#266](https://github.com/ricardoblackskye/webfeedpoc/issues/266)

## Goal

Add a home-route-only italic footer line to the existing ProductList component that HomePage renders, with a colocated Vitest test proving the exact text and route scope.

## Approach

The mechanical target list does not expose src/pages/HomePage.jsx, so the change is confined to the existing ProductList component that HomePage imports. ProductList will use react-router-dom's useLocation to render a footer paragraph only when pathname is '/'. The text is wrapped in `<em>` so it is italic without adding CSS. The colocated ProductList.test.jsx will be updated to wrap renders in MemoryRouter and assert both the home-route presence and non-home-route absence. No new dependencies or styles are introduced.

## Tasks

### 1. Add Dark Factory footer line to home page product list

**Objective:** Render the exact italic footer line only on the home route from src/components/ProductList.jsx and prove it with a colocated Vitest test.

**Files:** `src/components/ProductList.jsx`, `src/components/ProductList.test.jsx`

**Steps:**

1. Add a failing test in `src/components/ProductList.test.jsx` named `renders the Dark Factory footer line in italics on the home route`. Render `<ProductList products={[]} onAddToCart={() => {}} />` inside `<MemoryRouter initialEntries={['/']}>` and assert:
```jsx
const footerText = screen.getByText('Built by the Dark Factory - by the Developer Agent')
expect(footerText.tagName).toBe('EM')
expect(footerText).toHaveTextContent('Built by the Dark Factory - by the Developer Agent')
```
2. Add a second failing test in the same file named `does not render the Dark Factory footer line outside the home route`. Render the same component inside `<MemoryRouter initialEntries={['/category/antiques']}>` and assert:
```jsx
expect(screen.queryByText('Built by the Dark Factory - by the Developer Agent')).not.toBeInTheDocument()
```
3. Run `npx vitest run src/components/ProductList.test.jsx`. Expected: the home-route test fails because the footer text is not rendered; the non-home test passes.
4. Modify `src/components/ProductList.jsx`: import `useLocation` from `react-router-dom`, read `const { pathname } = useLocation()` inside the component, and render the following at the end of the product-grid JSX:
```jsx
{pathname === '/' && (
  <footer className="product-list-footer">
    <p><em>Built by the Dark Factory - by the Developer Agent</em></p>
  </footer>
)}
```
Keep all existing product-card rendering unchanged.
5. Run `npx vitest run src/components/ProductList.test.jsx`. Expected: all tests pass.
6. Run `npm run lint` and `npm run typecheck`. Expected: both pass with no new errors.
7. Commit the change:
```bash
git add src/components/ProductList.jsx src/components/ProductList.test.jsx
git commit -m "feat: add Dark Factory footer to home page"
```

**Verification:** Run `npx vitest run src/components/ProductList.test.jsx`; all tests pass. Run `npm run lint` and `npm run typecheck`; both pass.
