# Plan: Test issue for local run

Story: #285
Issue: [#285](https://github.com/ricardoblackskye/webfeedpoc/issues/285)

Scope: this story reads as shell-scoped work, so a target in the application shell is intended rather than accidental.

## Goal

Add a single italic credit line — 'This is Built by the Dark Factory - by the Developer Agent' — to the global site footer rendered by src/App.jsx, inline in the same `<p>` that already holds the copyright line, so it appears next to the copyright text at the bottom of the home page. No other markup, styling, route, data, or behaviour changes. The co-located spec src/App.test.jsx already exists in the repository and is therefore MODIFIED (new cases appended alongside its existing content) because this change alters rendered output.

## Approach

The story asks for a footer line on the home page, placed next to the copyright text. The copyright text is not rendered by the home page component (src/pages/HomePage.jsx renders the product grid, filters, sorting, pagination and modal only); it is rendered by the application shell src/App.jsx, whose `<footer className="app-footer"> contains the single <p>&copy; {year} {SITE_NAME}. All rights reserved.</p>. App.jsx renders <Outlet/> for every route, so it is the one component that owns the bottom-of-page copyright line on the home route. The change is therefore made in App.jsx and nowhere else: the credit is appended inside the existing <p>, after the copyright sentence, separated by an explicit JSX space so the two read as one line ('next to the copyright text'). Italics are produced semantically with an <em> element rather than a CSS class, because <em> is italic by default in every user agent and adding a rule would require touching src/App.css, which the story's 'no other changes' constraint discourages. The exact string is copied verbatim from the story, including the spaced hyphen: 'This is Built by the Dark Factory - by the Developer Agent'. src/App.test.jsx is the co-located spec for the shell being changed and ALREADY EXISTS in the repository, so it is modified (new cases added, existing content preserved) following the repository's established pattern (Vitest + @testing-library/react, co-located .test.jsx beside the unit under test). The new cases render the real App component inside MemoryRouter and HelmetProvider — required because App uses <Link>/<Outlet> and react-helmet-async — and mock the two data hooks (./hooks/useWixProducts, ./hooks/useWixCart) so the shell renders deterministically without Wix credentials or react-query. Assertions pin three things: the credit text exists inside an <em> (italics), it lives in the same <p>` as the copyright sentence and after it (placement), and the copyright sentence itself is unchanged (no other changes). Verification is the focused spec run, the full Vitest suite, and eslint.

## Tasks

### 1. Add the Dark Factory credit to the site footer (src/App.jsx) and extend the co-located spec (src/App.test.jsx)

**Objective:** Pin and then implement the italic footer credit 'This is Built by the Dark Factory - by the Developer Agent' so it renders inline, immediately after the existing copyright sentence in the global footer paragraph of src/App.jsx, with no other rendered change.

**Files:** `src/App.jsx`, `src/App.test.jsx`

**Steps:**

1. Step 1 — Write the failing tests. Open the EXISTING `src/App.test.jsx` (do not create it — it already exists in the repository) and append the following block to its current contents, leaving every pre-existing test and import untouched. The added block follows the repository's co-located Vitest + Testing Library pattern used by src/components/*.test.jsx:

```jsx
// -- Dark Factory footer credit (issue 285) --
import { MemoryRouter } from 'react-router-dom'
import { HelmetProvider } from 'react-helmet-async'
import App from './App'

// The shell renders before any Wix data exists; stub the data hooks so the
// footer can be asserted without credentials or react-query.
vi.mock('./hooks/useWixProducts', () => ({
  useWixProducts: () => ({ products: [], loading: false, error: null, refreshing: false }),
}))

vi.mock('./hooks/useWixCart', () => ({
  useWixCart: () => ({
    cart: [],
    loading: false,
    error: null,
    useWixBackend: false,
    addToCart: vi.fn(),
    removeFromCart: vi.fn(),
    updateQuantity: vi.fn(),
    totals: { subtotal: 0, discount: 0, shipping: 0, tax: 0, total: 0 },
  }),
}))

const CREDIT = 'This is Built by the Dark Factory - by the Developer Agent'

function renderApp() {
  return render(
    <HelmetProvider>
      <MemoryRouter>
        <App />
      </MemoryRouter>
    </HelmetProvider>
  )
}

describe('App footer', () => {
  it('renders the Dark Factory credit in italics', () => {
    renderApp()
    const footer = screen.getByRole('contentinfo')
    const credit = footer.querySelector('em')
    expect(credit).not.toBeNull()
    expect(credit.textContent).toBe(CREDIT)
  })

  it('renders the credit in the same paragraph as the copyright line, immediately after it', () => {
    renderApp()
    const footer = screen.getByRole('contentinfo')
    const paragraph = footer.querySelector('p')
    expect(paragraph).not.toBeNull()
    expect(paragraph.textContent).toContain('All rights reserved.')
    expect(paragraph.textContent).toContain(CREDIT)
    expect(paragraph.textContent.indexOf('All rights reserved.')).toBeLessThan(
      paragraph.textContent.indexOf(CREDIT)
    )
    expect(paragraph.querySelector('em')).not.toBeNull()
  })

  it('keeps the existing copyright text unchanged', () => {
    renderApp()
    const footer = screen.getByRole('contentinfo')
    expect(footer.textContent).toMatch(/©\s*\d{4}\s+.*All rights reserved\./)
    expect(footer.querySelectorAll('p')).toHaveLength(1)
  })
})
```

If the existing file already imports `describe`, `it`, `expect`, `vi`, `render`, or `screen`, do not duplicate those import statements — reuse them.

Run: `npx vitest run src/App.test.jsx`

The 'keeps the existing copyright text unchanged' case passes at this point, confirming the baseline, and any pre-existing tests in the file keep passing.
3. Step 3 — Implement the credit in `src/App.jsx`. Replace the existing footer block

```jsx
      <footer className="app-footer">
        <p>&copy; {new Date().getFullYear()} {SITE_NAME}. All rights reserved.</p>
      </footer>
```

with

```jsx

        <p>
          &copy; {new Date().getFullYear()} {SITE_NAME}. All rights reserved.{' '}

        </p>
      </footer>
```

No other line in src/App.jsx, and no other file, is touched. The credit is a plain-text child of an `<em>` (italic by default), kept inside the existing `<p>` so it renders on the same line as, and immediately after, the copyright sentence. The `{' '}` preserves the single separating space so the two sentences do not run together. No CSS is added: `<em>` is italic by default, and adding a rule would require modifying src/App.css, which the story's 'No other changes' constraint rules out.
