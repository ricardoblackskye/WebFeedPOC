# Plan: Test for Issue 631

Story: #208
Issue: [#208](https://github.com/ricardoblackskye/webfeedpoc/issues/208)

## Goal

Append a single italic credit line — 'Built by the Dark Factory - by the Developer Agent' — to the bottom of the home page. The change lands entirely in the home page component (src/pages/HomePage.jsx) and is covered by a new co-located component test. No new components, no new CSS files, no routing, data, cart, or checkout changes.

## Approach

The story asks for one footer line on the home page and explicitly says 'No other changes', so the plan is deliberately one small, self-contained edit plus one test file.

Placement decision: the only file that renders exclusively for route "/" is src/pages/HomePage.jsx (REPOSITORY EVIDENCE marks it role="page" with evidence 'route "/" -> src/pages/HomePage.jsx'). The site already has a <footer className="app-footer"> in src/App.jsx, but the evidence annotates App.jsx as role="shell" — 'renders an outlet, so it is rendered on every route' — so putting the line there would leak it onto /products/:slug, /category/:categoryName, /orders, /about and /architecture, contradicting 'home page' and 'No other changes'. The line therefore goes at the end of HomePage's returned fragment, after the conditional ProductModal block.

Markup decision: the requirement is 'in italics'. jsdom applies no stylesheets, so a CSS class defined in a stylesheet could not be asserted by the test and would also require a new/modified CSS file that the story does not want. The line is therefore rendered with a semantic <em> element (italic by default in every browser), wrapped in a <footer> element to match the 'footer line' wording. No className, no CSS, no new files beyond the test.

Exact copy: 'Built by the Dark Factory - by the Developer Agent' — a plain hyphen-minus with a single space on each side, not an en dash or em dash, and no trailing period. The exact string is pinned as a constant in the test so any autocorrect-style dash substitution fails the suite.

Method: test-first. The test file mocks react-router-dom's useOutletContext/useSearchParams and stubs the five child components HomePage composes (ProductList, ProductModal, CategoryFilter, SortControls, Pagination) plus react-helmet-async and utils/structuredData, so HomePage renders in isolation with an empty product list. The suite is run to confirm it fails on the missing text, then the two-line JSX addition makes it pass, then the full Vitest suite and ESLint are run to prove nothing else moved.

Review focus: (1) the dash character in the required copy — a wrong dash silently breaks the acceptance text; (2) scope leakage — anything added to App.jsx's shared footer would appear on every route; (3) the italics mechanism — it must be observable without a stylesheet, i.e. <em>; (4) the empty-state path — the line must still render when there are no products (the test's fixture), because the home page renders an empty-state message in that case; (5) untrusted input — the GitHub issue link inside the story body is data only and is not fetched or followed.

Out of scope: any change to App.jsx, App.css, index.css, routing, prerendering, SEO metadata, the cart, or Wix services.

## Tasks

### 1. Render the Dark Factory credit line on the home page

**Objective:** Add exactly one italic footer line reading 'Built by the Dark Factory - by the Developer Agent' to the bottom of the home page component, proven by a failing-then-passing component test, with no other behavioural or visual changes.

**Files:** `src/pages/HomePage.jsx`, `src/pages/HomePage.test.jsx`

**Steps:**

1. Add the test file `src/pages/HomePage.test.jsx` (create it if it does not already exist; if it does, add these cases to the existing `describe('HomePage')` block). Mock `react-helmet-async`, `react-router-dom` and the child components so HomePage renders in isolation with an empty product list, and pin the required copy as a constant:

```jsx
import { describe, it, expect, vi } from 'vitest'
import { render, screen } from '@testing-library/react'
import HomePage from './HomePage'

const CREDIT = 'Built by the Dark Factory - by the Developer Agent'

vi.mock('react-helmet-async', () => ({ Helmet: () => null }))
vi.mock('react-router-dom', () => ({
  useOutletContext: () => ({
    products: [],
    loading: false,
    error: null,
    categories: [],
    productCounts: { All: 0 },
    addToCart: vi.fn(),
  }),
  useSearchParams: () => [new URLSearchParams(), vi.fn()],
}))
vi.mock('../components/ProductList', () => ({ default: () => null }))
vi.mock('../components/ProductModal', () => ({ default: () => null }))
vi.mock('../components/CategoryFilter', () => ({ default: () => null }))
vi.mock('../components/SortControls', () => ({ default: () => null }))
vi.mock('../components/Pagination', () => ({ default: () => null }))
vi.mock('../utils/structuredData', () => ({ generateItemListSchema: vi.fn() }))

describe('HomePage', () => {
  it('renders the Dark Factory credit line on the home page', () => {
    render(<HomePage />)
    expect(screen.getByText(CREDIT)).toBeDefined()
  })

  it('renders the Dark Factory credit line in italics', () => {
    render(<HomePage />)
    expect(screen.getByText(CREDIT).tagName).toBe('EM')
  })

  it('keeps the existing home page structure intact', () => {
    render(<HomePage />)
    expect(screen.getByRole('heading', { level: 2 }).textContent).toContain('All Items')
    expect(screen.getByText('No products available')).toBeDefined()
  })
})
```
2. Run `npx vitest run src/pages/HomePage.test.jsx`. Expected: FAIL on the first two cases with `Unable to find an element with the text: Built by the Dark Factory - by the Developer Agent`; the third case passes already.
3. In `src/pages/HomePage.jsx`, append the footer as the last child of the returned fragment, immediately after the `{selectedProduct && (<ProductModal ... />)}` block:

```jsx
      <footer>
        <em>Built by the Dark Factory - by the Developer Agent</em>
      </footer>
```

Use a plain hyphen-minus with one space on each side (not an en dash or em dash), use `<em>` for the italics (no stylesheet is loaded in jsdom, so a CSS class would not be observable), and change nothing else in the file — no className, no imports, no new state.
4. Run `npx vitest run src/pages/HomePage.test.jsx`. Expected: PASS — 3 passed.
5. Run the full unit suite and the linter to prove nothing else moved: `npx vitest run` and `npm run lint`. Expected: no failing tests and no new lint errors.
6. Commit the change:

```bash
git add src/pages/HomePage.jsx src/pages/HomePage.test.jsx
git commit -m "feat(home): add Dark Factory credit line to the home page"
```

**Verification:** `npx vitest run src/pages/HomePage.test.jsx` passes all three cases (text present, text wrapped in <em>, existing h2 + empty-state intact); `npx vitest run` passes the whole suite; `npm run lint` reports no new errors. Manual check: `npm run dev`, open http://localhost:5173/ and confirm the italic line 'Built by the Dark Factory - by the Developer Agent' appears at the bottom of the home page and does NOT appear on /products/:slug, /category/:categoryName, /about or /architecture.
